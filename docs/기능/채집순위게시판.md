# 채집 순위 게시판

[명령어](../플러그인/ServerCore.md) · 농사·채광·벌목·낚시 **전체 누적 상위 10명**.

## 생성·조회

각 위치에서 관리자 명령을 실행합니다. 글은 현재 위치보다 3블록 위에 나타납니다.

```text
/rankboard create farm_top farming
/rankboard create mine_top mining
/rankboard create wood_top woodcutting
/rankboard create fish_top fishing
/rankboard list
/rankboard remove farm_top
```

플레이어 조회: `/순위 농사`, `/순위 채광`, `/순위 벌목`, `/순위 낚시`.
글자·배경 전체 크기는 기본의 **1.3배**이며 기존 게시판도 자동 적용됩니다.
게시판 이름은 영문·숫자·_·- 1~32자. 5초마다 갱신하고 오프라인도 포함합니다. 동점은 같은 순위(1, 1, 3)입니다.

## 기본 점수

| 분야 | 점수 예시 |
|---|---|
| 농사 | 밀·당근·감자 1 / 비트·호박 2 / 네더 사마귀·코코아 3 / 벌레잡이풀 8 |
| 채광 | 석탄·구리 2 / 철 4 / 금 6 / 다이아몬드 20 / 에메랄드 25 / 심층암 에메랄드 40 / 고대 잔해 50 |
| 벌목 | 모든 나무 1 |
| 낚시 | 대구 1 / 연어 2 / 복어 4 / 열대어 8 / 보물 20 |

보물: 마법책·이름표·앵무조개 껍데기·안장·활·마법 낚싯대. 잡동사니·일반 손상 낚싯대는 0점.

## 집계·설정

- 정상 파괴한 블록 한 개 또는 실제 낚시·열매 수확 한 번을 계산합니다. 추가 드롭은 점수를 늘리지 않습니다.
- 설치 블록 재채굴, 덜 자란 작물, 취소·실패한 작업, 크리에이티브·관전은 제외합니다. 심고 키운 작물·나무는 인정합니다.
- 각 분야가 추가된 버전 이후부터 집계합니다. 과거 기록 소급이나 주간 초기화는 없습니다.
- `ranking.yml`: `points` 배점, `woodcutting-points` 공통 나무 점수, `worlds` 집계 월드. 수정 후 `/코어 reload`.
- 기본 항목을 끄려면 **0점**으로 지정합니다. 삭제한 기본 항목은 기본값이 적용됩니다.
- `ranking-data.yml`: 점수·게시판 위치. 60초마다 및 정상 종료 시 저장, 이전 파일은 `.bak` 보존.

게시판 삭제는 점수를 지우지 않습니다. 기존 설정·농사·채광 기록을 삭제할 필요가 없습니다. 별도 리소스팩은 필요 없습니다.
