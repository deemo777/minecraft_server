# 농사·채광 누적 순위 게시판

블록 개수 대신 종류별 점수를 합산하는 전체 누적 순위입니다. 농사와 채광은 독립적이고 스킬 경험치·골드와 별개입니다. 신규 기능 적용 이후의 기록부터 집계하며, 과거 경험치에서 소급 계산하지 않습니다.

## 설치와 명령어

관리자는 게시판을 둘 자리에 서서 입력합니다. 글은 서 있는 위치보다 3블록 위를 기준으로 생성되며 보는 사람을 향합니다.

```text
/rankboard create farm_top farming
/rankboard create mine_top mining
/rankboard list
/rankboard remove farm_top
```

게시판 이름은 영문/숫자/_/- 1~32자이며 중복될 수 없습니다. 관리 권한은 `servercore.admin`, 별칭은 `/순위게시판`입니다. 게시판 제거는 점수를 삭제하지 않습니다.

일반 플레이어는 `/ranking farming`, `/ranking mining` 또는 `/순위 농사`, `/순위 채광`으로 채팅에서도 상위 10명을 볼 수 있습니다. 홀로그램은 5초마다 갱신하며 동점은 같은 순위(1, 1, 3)입니다. 오프라인 플레이어도 포함됩니다. 게시판은 청크가 로드되면 복원되고 청크를 강제로 계속 불러두지 않습니다.

## 점수 기준

`plugins/ServerCore/ranking.yml`을 수정하고 `/servercore reload`를 실행하세요. 이미 얻은 점수는 유지되며 이후 채집에 새 점수를 적용합니다.

- 농사 예시: 밀/당근/감자 1, 비트/호박 2, 네더 사마귀/코코아 3, 벌레잡이풀 8.
- 채광 예시: 석탄/구리 2, 철 4, 금 6, 다이아몬드 20, 에메랄드 25, 심층암 에메랄드 40, 고대 잔해 50.
- 돌과 심층암, 대나무는 기본 집계하지 않습니다. 점수는 희귀도와 생산 효율을 고려한 초기값이며 서버 환경에 맞게 조절하세요.
- 블록 한 개당 점수입니다. 행운·스킬 추가 드롭 개수는 점수를 늘리지 않습니다. 여러 줄기 작물이 함께 떨어져도 직접 깬 블록만 계산합니다. 열매 우클릭 수확은 한 번당 점수입니다.
- 작물은 설정의 `mature-only`에 해당하면 다 자란 것만 계산합니다. 직접 설치한 광석·호박·수박 등을 다시 부수는 것은 제외합니다. 작물을 심고 키워 수확하는 것은 정상 농사로 인정합니다.
- 취소된 채집, 드롭을 막은 파괴, 크리에이티브·관전 모드는 제외합니다. 피스톤 이동도 설치 기록을 옮깁니다.
- `worlds: []`는 모든 월드이며 원하는 월드 이름 목록으로 제한할 수 있습니다. 관리자 편집 도구가 직접 바꾼 블록이나 기능 도입 전 기록되지 않은 설치 블록은 출처를 소급 판별할 수 없습니다.

## 저장과 백업

`plugins/ServerCore/ranking-data.yml`에 UUID별 이름·점수·채집 횟수와 게시판 위치를 저장합니다. 60초마다 변경분을 저장하고 정상 종료 시에도 저장합니다. 게시판 생성·삭제는 즉시 저장합니다. 저장 전 이전 파일을 `.bak`으로 보존하고 임시 파일을 교체합니다. 강제 종료 시 마지막 자동 저장 이후 기록은 손실될 수 있습니다. 손상된 YAML은 덮어쓰지 않고 오류를 냅니다. 점수 데이터를 초기화하려면 서버를 끄고 먼저 백업하세요.

별도 리소스팩이나 추가 플러그인이 필요 없습니다. `features.ranking: false` 후 재시작하면 기능을 끕니다.
