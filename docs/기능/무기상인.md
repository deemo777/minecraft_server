# 무기 상인

[전체 명령어](../플러그인/ServerCore.md)

고글·청록 작업복·가죽 앞치마를 입은 전용 3D NPC입니다. 주민 외형·소리를 사용하지 않습니다.
집터를 설치한 플레이어만 우클릭해 마을 도구 5종의 **0강 장비**를 골드로 삽니다. 일반 검·방어구는 판매하지 않습니다.

```text
/npc create weaponmerchant
/weaponmerchantnpc face
/weaponmerchantnpc remove
/weaponshop [player]
```

관리자 전용 명령어는 `/weaponmerchantnpc`, `/weaponshop`입니다. NPC는 블록 중앙에 생성되고 방향·위치를 저장합니다.
`face`·`remove`는 5블록 안의 가장 가까운 무기 상인에게 적용됩니다. 방향은 실행자 시선의 반대입니다.

| 장비 | 기본 가격 |
|---|---|
| 곡괭이 | 1,000G |
| 도끼 | 1,000G |
| 괭이 | 800G |
| 낚싯대 | 500G |
| 물뿌리개 | 500G |

`plugins/ServerCore/weapon-shop.yml`의 `prices`를 바꾸고 `/servercore reload`합니다. 0 이하면 판매를 중지합니다.
일반 좌/우클릭마다 1개를 구매합니다. Shift·숫자키·드래그 구매는 막으며 공간·잔액이 부족하면 결제하지 않습니다.

`features.weapon-merchant`, `features.economy`, `features.tools`가 켜져 있어야 합니다. 외형을 보려면 **최신 통합 리소스팩**이 필요합니다.

집터 아이템 수령만으로는 구매할 수 없습니다. 구매 직전에도 소유 부지를 다시 확인합니다. 도구 이름은 `광 + 도구명`으로 통일합니다.
