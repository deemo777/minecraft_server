# 광쿠키와 요리사

[전체 명령어](../플러그인/ServerCore.md)

| 항목 | 현재 동작 |
|---|---|
| 아이템 이름 | 광쿠키 |
| 설명 | 바삭하게 구운 광태의 얼굴 |
| 무료 수량 | 우클릭마다 16개, 0.5초 간격 |
| 회복 | 허기 10·포화도 12 (빵의 2배) |
| 요리사 외형 | deemo777 실제 얼굴·흰 제빵모자·분홍 앞치마 |
| 소리 | 수령한 본인에게 작은 하프 두 음, 주민 소리 없음 |

```text
/cookienpc create
/cookienpc face
/cookienpc remove
```

`face`는 5블록 안의 요리사를 현재 시선 반대 방향으로 돌립니다. 블록 중앙에 생성되고 방향은 저장됩니다.
인벤토리에 16개가 모두 들어갈 공간이 있어야 받습니다. 기존 쿠키 주민은 청크 로드 시 새 외형으로 전환됩니다.

요리사는 ItemDisplay+Interaction으로 표시하므로 최신 **통합 리소스팩이 필요**합니다. 엔티티 정리 플러그인에서 두 종류를 지우지 않도록 설정하세요.
기존에 받은 쿠키의 이름·설명은 유지됩니다. 새로 받으면 최신 표시가 적용됩니다.
