# 대장간과 강화

[전체 명령어](../플러그인/ServerCore.md)

대장장이 우클릭 → 왼쪽 장비 1개·오른쪽 전용 결정 → 아래 강화 버튼.
대상은 마을 도구 5종이며 일반 검·방어구는 아닙니다.

```text
/npc create blacksmith
/blacksmithnpc remove
/blacksmithnpc face
/enhance [player]
/enhance material pickaxe 64
/villagetool give pickaxe 0
```

모든 위 명령은 관리자용입니다. 도구 종류: `pickaxe`, `axe`, `hoe`, `fishing_rod`, `watering_can`.

## 전용 재료

마을 도구로 정상 작업 시 기본 **10%로 결정 1개**가 떨어집니다.

| 도구 | 작업 |
|---|---|
| 곡괭이 | 돌·광석 채굴 |
| 도끼 | 나무 채집 |
| 괭이 | 다 자란 작물 수확 |
| 낚싯대 | 실제 낚시 성공 |
| 물뿌리개 | 마른 경작지에 물주기 |

설치한 돌·나무 재채굴, 크리에이티브·관전, 취소된 작업은 제외합니다. 일반 자수정은 재료가 아닙니다.

## 강화 규칙

| 목표 단계 | 결정 소모 | 단계별 성공률 |
|---|---|---|
| +1~5 | 1개 | 100 / 95 / 90 / 85 / 80% |
| +6~10 | 2개 | 75 / 70 / 65 / 60 / 55% |
| +11~15 | 3개 | 50 / 45 / 40 / 35 / 30% |
| +16~20 | 4개 | 25 / 20 / 15 / 12 / 10% |

실패해도 결정을 소비하며 골드는 들지 않습니다. +1~10 시도는 유지, +11~15 실패는 30%로 하락(최저 +10), +16~20 실패는 50%로 하락(최저 +15). 파괴는 없습니다.
창 닫기·로그아웃 시 넣은 아이템을 반환합니다. 사망은 keepInventory 규칙에 맞춰 처리합니다.

`tools.yml`의 `enhancement.drop-chance`·`enhancement.success-rates`를 수정하고 `/servercore reload`합니다.
0강 도구 구매는 [무기 상인](무기상인.md)에서 합니다. 수리·물 저장과 리필은 아직 없습니다. 배포는 **통합 servercore_pack.zip**을 사용하세요.

낚싯대도 0/5/10/15/20강마다 입체 외형이 바뀝니다. 찌를 던지면 전용 cast 외형으로 바뀌며 기존 마을 낚싯대는 재접속·손 변경·가방 닫기 시 갱신됩니다. 일반 낚싯대 외형은 유지합니다.

## 광 도구 성능 (3.25.0)

이름은 광 곡괭이·광 도끼·광 괭이·광 낚싯대·광 물뿌리개로 고정하며 강화 색상과 +단계는 유지합니다.

| 곡괭이 강화 | 효율 | 행운 |
|---|---|---|
| 0 | 없음 (다이아 기본) | 없음 |
| 5 | II | I |
| 10 | V | III |
| 15 | VI | IV |
| 20 | VII | IV |

중간 효율은 0~10에서 `floor(단계×0.5)`, 10~20에서 `5+floor((단계-10)×0.2)`입니다.
행운은 0~10에서 `floor(단계×0.3)`, 10~15에서 `3+floor((단계-10)×0.2)`이며 15 이후 IV로 고정합니다.
바닐라 행운 드롭 규칙을 사용하며 별도 채광 스킬 두 배 보너스는 중첩하지 않습니다.

도끼는 자연 원목 두 배 드롭 확률 `단계×2.5%` (20강 50%). 벌목 스킬의 두 배 확률과 중첩하지 않습니다.
20강은 자연 잎/균사 수관이 있는 연결된 같은 종류 원목을 자동 벌목합니다. 각 블록의 보호 이벤트와 내구도를 적용합니다.
플레이어가 설치한 원목은 추가 드롭·연쇄 벌목에서 제외합니다. 괭이·낚싯대·물뿌리개 동작은 기존 그대로입니다.
큰 나무도 안전하게 처리하도록 한 번에 최대 4,096개, 틱당 64개, 좌우 32·높이 64블록 범위와 로드된 청크로 제한합니다.

기존 도구는 접속·손 교체·습득·인벤토리 닫기·설정 재로드 시 갱신됩니다. 리소스팩 변경은 없습니다.
