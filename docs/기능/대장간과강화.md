# 대장간·확률 강화

ServerCore 3.15.0. 마을 도구 5종의 단계 강화용입니다. 일반 검·방어구는 대상이 아닙니다.
대장장이를 우클릭하면 왼쪽 장비(1개), 오른쪽 전용 결정, 중앙 아래 강화 버튼이 있는 화면이 열립니다.
일반 클릭·우클릭·가방 Shift+클릭을 지원합니다. 입력 칸으로 드래그·숫자키·더블클릭 이동은 막습니다.
창 닫기·로그아웃·플러그인 종료 때 아이템을 돌려주고, 가방이 가득 차면 발밑에 놓습니다.
사망 시 서버의 keepInventory 처리에 맞춰 반환 또는 사망 드롭에 포함합니다.

## NPC와 관리자 명령어

```text
/blacksmithnpc create
/blacksmithnpc remove
/enhance
/enhance 플레이어
/enhance material pickaxe 64
/enhance material axe 64 플레이어
```

NPC 명령어 별칭은 `/대장장이`, 강화 관리 명령어 별칭은 `/강화`입니다.
모든 명령어는 OP 또는 `servercore.admin` 권한이 필요합니다. 일반 플레이어는 NPC로 이용합니다.
`remove`는 5블록 안에서 가장 가까운 대장장이 하나만 없앱니다.
NPC는 무기 대장장이 주민이며 이동·일반 거래·피해·변신을 막고 월드에 저장됩니다.
`features.tools`가 켜져 있어야 하고 `features.blacksmith`를 false로 하면 기능을 끕니다.

## 전용 강화 결정 드롭

각 작업이 성공하면 10% 확률로 해당 도구의 결정 1개가 월드에 떨어집니다.
마을 도구를 실제로 써야 하며 크리에이티브·관전자, 취소된 행동에는 지급하지 않습니다.
일반 자수정이나 다른 도구 결정은 강화 재료로 인정하지 않습니다. 이름이 아닌 PDC로 식별합니다.

| 도구 | 작업 |
|---|---|
| 곡괭이 | 돌·심층암·화강암·섬록암·안산암·응회암·방해석·네더랙·현무암·흑암·엔드석·광석·고대 잔해 채굴 |
| 도끼 | 원목·통나무 계열 파괴 |
| 괭이 | 다 자란 Ageable 작물 수확 |
| 낚싯대 | 해당 마을 낚싯대로 실제 낚시 아이템 획득, 양손 구분 |
| 물뿌리개 | 마른 경작지를 우클릭해 적실 때 |

직접 설치한 돌·원목은 청크 PDC로 기억하며 재설치 채굴은 제외합니다. 기존 스킬의 설치 기록도 확인합니다.
괭이는 씨앗을 심어 정상적으로 자란 작물을 수확할 수 있습니다.
물뿌리개는 이번에 한 칸 물주기를 연결했습니다. 이미 젖은 밭 연타는 결정이 나오지 않습니다.
물 저장량·리필·넓은 범위 물주기는 아직 없으며, 권한 때문에 취소된 상호작용은 처리하지 않습니다.

## 강화 규칙

| 목표 단계 | 매 시도 결정 소모 | 성공률 |
|---|---|---|
| +1~5 | 1개 | 100 / 95 / 90 / 85 / 80% |
| +6~10 | 2개 | 75 / 70 / 65 / 60 / 55% |
| +11~15 | 3개 | 50 / 45 / 40 / 35 / 30% |
| +16~20 | 4개 | 25 / 20 / 15 / 12 / 10% |

실패에도 재료를 소비합니다. 골드는 받지 않습니다.
실패 시 +1~10 시도는 단계 유지, +11~15 시도는 30% 확률로 1단계 하락(최저 +10),
+16~20 시도는 50% 확률로 1단계 하락(최저 +15)합니다. 장비는 파괴하지 않습니다.
이름·별·모델 단계가 즉시 갱신되며 내구도와 기존 메타데이터는 유지합니다. 최대 +20입니다.
연타 방지를 위해 강화 버튼은 0.3초 간격으로 처리합니다.

`tools.yml`의 `enhancement.drop-chance`와 `enhancement.success-rates`를 바꾸고 `/코어 reload`하면 적용됩니다.
기존 운영 tools.yml에 새 항목이 없어도 JAR의 기본값을 사용합니다.
확률 강화를 넣었지만 장비별 광역 채굴·드롭 배수·수리·구매 GUI는 아직 구현하지 않았습니다.

## 리소스팩과 배포

- `servercore_pack.zip`: 기존 모델·메뉴·HUD를 보존한 통합 팩. 현재 서버 배포에는 이것을 사용합니다.
- `servercore_enhancement_pack.zip`: 대장간 화면·결정만 있는 전용 팩. 기존 전체 팩을 대체하는 용도는 아닙니다.
- 전용 폰트 `servercore:forge`로 분리해서 기존 메뉴 폰트와 충돌하지 않습니다.
- 배경 코드는 E070~E073, 입력 슬롯은 11/15, 버튼은 22(그림 범위에 맞춰 21~23 클릭 허용)입니다.
- 생성 코드: `tools/make_blacksmith_art.py`. `build_pack.py`에도 연결되어 재빌드 시 포함됩니다.
- 새 JAR 한 개만 plugins에 넣고 통합 팩 URL·SHA-1을 갱신한 뒤 서버를 재시작합니다.
- 기존 운영 guide.yml은 덮어쓰지 않으므로 새 기본 안내서의 대장간 부분을 합치면 좋습니다.

검증: Java 25 빌드, 강화 규칙 88개, 기존 집터 규칙 60개와 저장 회귀 검사,
팩 JSON·폰트·PNG·기존 리소스 보존 검사를 통과했습니다.
실제 Paper 접속으로 클릭·월드별 보호·낚시·NPC 저장을 확인하는 운영 테스트는 별도입니다.

생성 시 서 있는 블록의 X·Z 중앙에 배치됩니다. 발 높이는 유지하며, 기존 NPC는 제거 후 다시 생성하면 중앙 정렬이 적용됩니다.
