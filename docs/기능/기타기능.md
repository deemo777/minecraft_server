# 기타 ServerCore 기능

이 문서는 NPC와 커스텀 도구·강화를 제외한 플레이 기능, 최초 설정, 저장 파일, 빌드·배포 정보를 모읍니다. 전체 명령은 [ServerCore 명령어](../플러그인/ServerCore.md)를 참고하세요.

## 플레이 기능

| 기능 | 사용법·요약 |
|---|---|
| 메뉴·이동 | 웅크리기+F 또는 `/menu`. 위치는 `/servercore setpoint <name>`으로 지정 |
| 도감 | `/dogam`, 발견 항목과 보상 기록 |
| 골드 | `/money`, 골드 주머니 입금·인출 |
| 집터·부지 | 이장에게 집터를 받아 마을에 2×2 부지를 예약하고, 빚을 갚아 청크를 한 칸씩 해방 |
| 스킬·칭호 | 농사·채광·벌목·낚시·전투 성장, `/skill`, `/honor` |
| HUD·안내서 | `/hud`, `/guide` |
| 상점 | NPC를 클릭해 아이템 판매·구매; 농지 상인이 비옥한 농지를 판매 |
| 농지 | 농지 상점에서 산 비옥한 농지를 해방된 내 집 부지에 설치. 물 공급을 유지하고 밟힘을 방지 |
| 순위 | 농사·채광·벌목·낚시 점수 누적, `/ranking`, 홀로그램 게시판 |
| 이동 보조 | 관리자 `/jumppad`, 달리면서 점프하는 도약 |

## 비옥한 농지

농작물 상인과 별도로 세운 농지 상인 NPC의 `farmplots` 상점에서 한 개 **500G**에 삽니다. `/npc create farmplots`로 생성합니다. 비옥한 농지를 들고 본인이 사용할 수 있는 해방된 집 부지에 설치하면 일반 경작지와 같은 속도로 작물이 자라며, 엔티티가 밟아도 흙으로 변하지 않습니다. 물이 공급되어 수분이 오른 뒤 작물이 자라는 동안에는 수분을 유지합니다. 다 자란 작물을 캐면 수분이 0으로 초기화되어 다음 작물을 심기 전에 다시 물을 공급해야 합니다.

일반 괭이로 만든 밭은 기존보다 작물이 느리게 자랍니다. 비옥한 농지는 일반 밭의 기본 성장 속도를 유지하는 대신, 물 공급 유지와 밟힘 방지를 제공합니다. 기존 농사 경험치·순위 점수는 두 밭 모두 유지되며, 농지 블록을 캐면 아이템을 돌려받습니다. 가격은 `shops.yml`의 `shops.farmplots.items.farm_plot.buy`에서 바꾸고 `/servercore reload`로 적용합니다.

## 집터 사용

집터를 든 채 바닥을 가리키면 6블록 안에서 2×2 부지 미리보기를 볼 수 있습니다. 외곽은 높이 2블록의 반투명 유리벽으로 표시되고, 4블록 간격과 모서리에 빨간 세로 줄무늬가 보입니다. 웅크리고 우클릭해 북서→북동→남동→남서 모서리를 선택하고, 웅크리기를 풀어 우클릭하면 설치합니다. 선택은 재접속하면 북서로 초기화됩니다.

| 단계 | 기본 빚 |
|---|---:|
| 첫 집터 청크 설치 | 50,000G |
| 두 번째 청크 해방 | 150,000G |
| 세 번째 청크 해방 | 500,000G |
| 네 번째 청크 해방 | 1,000,000G |

이장에게 현재 빚 전액을 갚은 뒤 `/land` 집 지도에서 다음 청크를 해방합니다. 잠긴 칸은 집주인과 이웃도 사용할 수 없습니다. `/land trust <name>`·`/land untrust <name>`은 이웃 권한을 관리하며, `/land home`·`/land sethome`은 귀환 위치를 관리합니다. 집 포기·관리자 삭제는 건축물을 철거하거나 복원하지 않습니다.

집 설치 허용 구역은 village 월드에서 `/land zone pos1`, `/land zone pos2`, `/land zone add`로 정합니다. 선택은 청크 단위입니다. 범위를 비워 두면 마을 전체를 허용합니다.

## 순위 게시판

게시판을 둘 자리에 관리자 명령을 실행하면 글이 현재 위치보다 3블록 위에 표시됩니다.

```text
/rankboard create farm_top farming
/rankboard create mine_top mining
/rankboard create wood_top woodcutting
/rankboard create fish_top fishing
/rankboard list
/rankboard remove farm_top
```

기본 점수는 밀·당근·감자 1, 비트·호박 2, 네더 사마귀·코코아 3, 벌레잡이풀 8; 석탄·구리 2, 철 4, 금 6, 다이아몬드 20, 에메랄드 25, 심층암 에메랄드 40, 고대 잔해 50; 나무 1; 낚시는 대구 1·연어 2·복어 4·열대어 8·보물 20입니다. 게시판은 상위 10명을 5초마다 갱신하며 동점은 공동 순위입니다.

설치는 정상 채굴·수확·낚시만 집계합니다. 추가 드롭은 점수에 포함하지 않고, 설치 블록 재채굴·덜 자란 작물·취소된 작업·크리에이티브·관전은 제외합니다. `ranking.yml`에서 배점과 집계 월드를 설정하고 `/servercore reload`합니다. 점수·게시판 위치는 `ranking-data.yml`에 저장됩니다. 게시판을 지워도 점수는 유지됩니다.

## 최초 월드 설정

각 월드의 도착 지점에서 Multiverse 월드 스폰과 ServerCore 메뉴 지점을 각각 설정합니다.

```text
/mv setspawn
/servercore setpoint lobby
/servercore setpoint village
/servercore setpoint wild
```

이후 마을의 집 구역과 게시판 위치를 지정합니다. NPC를 세우고 일반 플레이어 권한으로 NPC 클릭·집터 설치·접근 권한·순위 표시를 점검합니다. Multiverse 월드 스폰과 ServerCore 메뉴 지점은 서로 다른 설정입니다.

## 설정 파일과 저장 데이터

서버의 `plugins/ServerCore/` 기준입니다. 기존 설정 파일을 새 JAR 파일로 통째로 덮어쓰지 마세요.

| 파일 | 역할 | 적용 |
|---|---|---|
| `config.yml` | 기능 켜기/끄기, 집터, 골드, HUD, 도약 | `/servercore reload`; 기능 활성화 변경은 재시작 |
| `menu.yml` | 메뉴 버튼·이동 지점 연결 | `/servercore reload` |
| `dogam.yml` | 도감 항목 | `/servercore reload`; 새 모델은 리소스팩 재빌드 |
| `shops.yml` | 상점 품목·가격·NPC ID (농지 기본 500G) | `/servercore reload` |
| `skills.yml` | 경험치·칭호·레벨 효과 | `/servercore reload` |
| `tools.yml` | 마을 도구·강화 확률·재료 드롭 | `/servercore reload` |
| `weapon-shop.yml` | 모험가 상인의 0강 도구 가격 | `/servercore reload` |
| `ranking.yml` | 순위 배점·집계 월드 | `/servercore reload` |
| `guide.yml` | 서버 안내서 | `/servercore reload` |

`points.yml`은 메뉴 이동 지점, `lands.yml`은 집·예약 청크·빚·이웃, `land-zones.yml`은 집터 설치 구역, `ranking-data.yml`은 누적 점수·게시판 위치를 저장합니다. `money.yml`, `skill-data/`, `dogam-data/`에는 플레이어 데이터가 있습니다. 월드의 청크·엔티티 데이터에도 NPC와 설치 블록 기록이 있으므로 월드와 함께 백업합니다.

## 빌드와 배포

개발 환경은 Java 25입니다. `D:\Games\minecraft\Server\ServerCore_2`에서 다음 명령을 실행합니다.

```powershell
.\gradlew.bat clean build
python tools/build_pack.py --jar "$env:APPDATA\.minecraft\versions\26.3\26.3.jar" --dogam src/main/resources/dogam.yml
```

JAR는 `build/libs/ServerCore-<버전>.jar`, 전체 리소스팩은 `tools/build/servercore_pack.zip`에 생성됩니다. 플러그인과 팩은 별도로 배포합니다. JAR 교체 전 서버를 정상 종료하고 월드와 `plugins/ServerCore/`를 백업한 뒤, 기존 ServerCore JAR 하나를 새 파일로 바꾸고 재시작합니다. 적용 버전은 `/version ServerCore`로 확인합니다.

전체 서버용 팩은 GitHub의 [servercore 릴리스](https://github.com/deemo777/minecraft_server/releases/tag/servercore)에서 받습니다. 팩을 교체하면 다운로드된 ZIP의 SHA-1을 확인한 다음 서버 루트의 `server.properties`에 `resource-pack`과 `resource-pack-sha1`을 설정하고 서버를 재시작합니다. 현재 릴리스 ZIP SHA-1: `ac148b2b6b0a321f5ff98373f064f947e66be6de`.

코드는 `src/main/java/com/htk/core/`, 리소스 생성기는 `tools/`에 있습니다. Git 원격은 `deemo777/minecraft_server`의 `plugins` 브랜치입니다. 월드, 저장 데이터, `.env`와 비밀 인증 정보는 소스 Git에 넣지 않습니다.

| 코드 경로 | 담당 |
|---|---|
| `ServerCore.java`, `common/` | 기능 초기화·공통 GUI·아이템·문자 |
| `land/` | 집터·부지·빚·보호·저장 |
| `tools/` | 도구·대장장이·강화·결정 |
| `npc/`, `mayor/`, `shop/`, `merchant/`, `cookie/` | 공통 NPC·이장·상점·모험가·광쿠키 요리사 |
| `ranking/`, `skill/`, `hud/`, `dogam/`, `menu/`, `guide/` | 순위·스킬·칭호·HUD·도감·메뉴·안내서 |

`gradlew.bat clean build`는 단위 테스트와 명령어·강화·집터·NPC 방향·구매·순위 검증을 함께 실행합니다. 리소스팩 생성기와 모델·텍스처는 `tools/` 아래에 있습니다.
