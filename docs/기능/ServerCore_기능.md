# 기능 요약

[명령어](../플러그인/ServerCore.md)

| 기능 | 사용법 |
|---|---|
| 메뉴·이동 | 웅크리기+F 또는 `/메뉴`, 지점은 `/servercore setpoint` |
| 도감 | `/도감`, 항목 등록과 보상 |
| 골드·상점 | `/money`, 상점 NPC 우클릭으로 판매 |
| 이장 | 첫 대화로 집터 수령·집 빚 상환 |
| 집터 | village에서 2×2 부지 예약, 모서리 선택·미리보기·단계 해방 |
| 스킬·칭호 | 농사·채광·벌목·낚시·전투, `/skill`·`/칭호` |
| HUD·안내서 | `/hud`, `/guide` |
| 강화 | 대장장이에 장비·전용 재료를 넣어 +20까지 |
| 광쿠키 | 요리사 우클릭으로 16개 무료 수령 |
| 순위 | 네 분야별 가중 포인트 누적·홀로그램 |
| 점프 패드·도약 | 관리자 `/jumppad`, 달리며 점프 |
