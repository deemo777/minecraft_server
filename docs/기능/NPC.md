# NPC

ServerCore NPC를 한 명령으로 관리합니다. 생성·제거·방향 변경은 관리자 권한이 필요하며, NPC 종류는 명령의 두 번째 값으로 지정합니다.

| NPC | 머리 위 이름 | 종류 ID |
|---|---|---|
| 이장 | 이장 | `mayor` |
| 대장장이 | 대장장이 | `blacksmith` |
| 생선 상인 | 어부 | `fish` |
| 농작물 상인 | 농부 | `crops` |
| 상인 (농지 판매) | 상인 | `farmplots` |
| 광물 상인 | 광부 | `ores` |
| 광쿠키 요리사 | 광쿠키 요리사 | `cookie` |
| 도구 상인 | 잊혀진 명장 | `weaponmerchant` |
| 무기 상인 | 무기 상인 | `armsmerchant` |

## 명령어

```text
/npc create <종류>
/npc remove <종류>
/npc face <종류>
/npc reset mayor <player>
```

`create`는 실행자의 현재 위치 블록 중앙에 NPC를 세우고 실행자를 바라보게 합니다. `remove`와 `face`는 5블록 안에서 지정한 종류의 가장 가까운 NPC를 대상으로 합니다. `face`는 실행자의 시선 반대 방향으로 돌립니다. 상점 NPC 종류는 `shops.yml`의 ID를 사용합니다.

`reset mayor`는 접속 중인 플레이어의 이장 첫 대화 기록을 초기화합니다. 이미 설치한 집과 아이템은 유지됩니다.

## 외형·저장

주민형 NPC와 광쿠키·무기 상인은 영구 저장되는 `Interaction` 엔티티와 리소스팩 모델로 표시합니다. 최신 통합 리소스팩이 있어야 커스텀 외형이 보입니다. 이름표는 서버에서 표시하며 리소스팩이 필요하지 않습니다.

기존 주민형 NPC는 청크가 로드될 때 같은 위치의 모델 NPC로 전환합니다. 기존 NPC도 청크가 로드되면 이름표가 적용됩니다. 엔티티 정리 플러그인에서 `Interaction`과 `ItemDisplay`를 삭제하지 않도록 설정하세요.

| 종류 | 모델·상호작용 |
|---|---|
| 이장 | 첫 대화에서 집터 수령·빚 상환 안내 |
| 대장장이 | 마을 도구 강화 |
| 생선·농작물·농지·광물 상인 | 해당 상점 열기 |
| 광쿠키 요리사 | 광쿠키 16개 무료 지급 |
| 잊혀진 명장 | 첫 만남 대화 후 집터를 설치한 플레이어에게 마을 도구 0강 판매 |
| 무기 상인 | 대사 없이 구매 창 열기 · 집터 설치 후 단검·태도·대검 0강 판매 |

광쿠키의 얼굴은 쿠키 안쪽 원에 맞춰 표시해 아래 좌우 모서리가 흰 아이싱 테두리를 덮지 않습니다. 얼굴의 원래 색과 픽셀 확대 배율은 유지합니다.

## 잊혀진 명장과의 첫 만남

처음 우클릭하면 명장의 대사 4개가 3.5초 간격으로 **클릭한 플레이어의 채팅에만** 표시됩니다. 마지막 대사를 읽을 시간을 둔 뒤 구매 창을 엽니다. 플레이어의 응답 대사는 없습니다.

> …이런 곳까지 발길이 닿다니. 길을 잃은 건가, 낯선 이여?
>
> 한때는 내 망치가 빚은 물건을 전설이라 불렀지. 이제는 내 이름조차 기억하는 이가 없네.
>
> 힘은 예전 같지 않아도, 쓸 만한 도구를 고르는 눈까지 녹슬지는 않았네.
>
> 마침 남겨 둔 물건들이 있군. 자네의 여정에 쓸 것이 있다면 하나 골라 보게.

완료 여부는 플레이어 PDC의 `servercore:weapon_merchant_intro_done`에 저장됩니다. 이후 우클릭은 바로 구매 창을 열며 재접속·서버 재시작에도 기록을 유지합니다. 대화 중 연속 클릭은 대사를 겹쳐 보내지 않습니다. 접속 종료·사망·NPC에서 8블록 초과 이탈·월드 이동·NPC 제거·기능 종료 시 대화가 취소되며 다음 만남에 처음부터 다시 진행합니다. 집터가 없으면 첫 대화 후 개인 안내를 보내고 구매를 제한합니다. 관리자 `/weaponshop [player]`는 첫 만남 기록을 바꾸지 않고 구매 창을 직접 엽니다.

구매 창은 대장간과 같은 철제 테두리·구리 리벳·따뜻한 간판 색상을 씁니다. 가운데 줄은 왼쪽부터 곡괭이(9번)·도끼(11번)·낚싯대(13번)·괭이(15번)·물뿌리개(17번), 돌아가기는 22번입니다. 슬롯은 0부터 셉니다. 슬롯과 돌아가기 버튼은 바깥 박스 안에 배치하며 버튼과 하단 테두리는 2px 떨어져 있습니다. 하단에는 게임 기본 보관함 글자만 표시해 배경의 가방 글자와 겹치지 않습니다. 리소스팩을 끄면 제목과 기본 아이템으로 구매할 수 있습니다. 대사와 구매 안내는 수신자 이름과 함께 서버 로그에도 남습니다.

상점·NPC 기능은 기존 전용 명령어도 호환하지만, 새 설정과 운영에는 `/npc` 명령을 사용하세요.

잊혀진 명장의 0강 도구는 **곡괭이·도끼·낚싯대 1,000G, 괭이·물뿌리개 500G 고정**입니다. 기존 `weapon-shop.yml`의 `prices` 값은 사용하지 않습니다. 신규 골드 계정은 최초 접속 시 3,000G를 받으며 기존 계정 잔액을 접속할 때마다 초기화하지 않습니다.


## 무기 상인 (4.7.0)

`/npc create armsmerchant`로 도구 상인과 별도의 무기 상인을 만듭니다. `/armsmerchantnpc remove|face`로 제거·방향을 조절하고 `/armsshop [player]`로 관리자 구매 창을 엽니다. 단검·태도·대검 0강을 각 1,000G에 판매하며 집터 설치가 필요합니다. 강화·재료·수리는 [무기와 스킨](../기능/무기와스킨.md)을 참고하세요.

4.9.2부터 첫 만남 대사 없이 우클릭하면 바로 구매 창을 엽니다. 집터가 없으면 구매 조건 안내만 표시합니다. 기존 대화 완료 데이터는 더 이상 읽거나 쓰지 않습니다. 명장의 첫 만남 대화는 유지합니다.

외형은 금발·남색 제복과 모자·붉은 스카프·금속 견갑·옆 검집으로 구성한 전용 `servercore:arms_merchant` 모델입니다. 기존 무기 상인도 새 팩을 받으면 바뀐 모습으로 표시되며 재생성할 필요가 없습니다. 명장의 청록색 앞치마와 고글 모델은 유지합니다.

단검·태도·대검 이름은 각각 11·13·15번 슬롯 위에 표시하고, 상품 툴팁에는 가격 한 줄만 남깁니다. 구매 후 실제 장비에는 기존 능력치 설명을 제공합니다. 돌아가기 버튼은 22번이며 설명 대사는 표시하지 않습니다.
