# 집터와 2×2 고정 부지

[전체 문서](../README.md) · [명령어](../플러그인/ServerCore.md)

ServerCore 3.14.0 기준입니다. 집터는 `village`에서만 설치할 수 있습니다.
집 사이에 별도의 빈 청크 간격은 요구하지 않습니다. 두 집의 부지가 겹치는 것만 막습니다.

## 부지를 정하는 방법

집터 청크를 북서쪽 모서리로 하여 동쪽·남쪽으로 2×2 부지(32×32블록)를 미리 확보합니다.
집터를 놓을 때 바라본 방향은 집 모형과 지도 방향에 쓰며, 부지 확장 방향을 선택하는 기능은 없습니다.

```text
북쪽
[집터: 처음 사용] [두 번째 해방]
[세 번째 해방]   [네 번째 해방]
                         남쪽
```

설치 조건: 집이 아직 없음, 마을 월드, 4청크 전체가 집 구역 안, 다른 집의 예약·사용 부지와 겹치지 않음.
집 구역을 하나도 지정하지 않았다면 기존과 같이 마을 전체를 허용합니다.

## 빚과 청크 해방

| 단계 | 사용할 수 있는 땅 | 생기는 빚(기본값) |
|---|---|---|
| 집터 설치 | 집터 1청크 | 50,000G |
| 첫 빚 전액 상환 후 지도에서 해방 | 2청크 | 150,000G |
| 현재 빚 전액 상환 후 지도에서 해방 | 3청크 | 500,000G |
| 현재 빚 전액 상환 후 지도에서 해방 | 4청크 | 1,000,000G |

현재 빚을 갚았다고 다음 청크가 자동으로 열리지는 않습니다. `/land`에서 다음 칸을 선택하고 확인합니다.
해방한 청크는 바로 사용할 수 있고 다음 빚이 생깁니다. 빚 갚기는 기존처럼 로비 이장님을 이용합니다.
금액은 `land.first-cost`, `land.expand-costs` 설정을 그대로 사용합니다.

잠긴 칸도 내 예약 부지이므로 다른 플레이어는 집터를 설치할 수 없습니다.
해방 전에는 주인·이웃도 그 청크에서 건축·상자 사용·동물 조작 등을 할 수 없습니다. 이동 자체는 허용합니다. 테두리 보기는 초록색이 사용 중인 땅, 하늘색이 잠긴 부지입니다.
관리자 `/land bypass`는 잠금 보호도 우회합니다. 일반 플레이어 허가와 구분합니다.
사용 가능한 청크와 잠긴 청크 사이의 물·피스톤·나무 성장 경계 이동도 차단합니다.

## 기존 집 데이터

`lands.yml`의 `chunks`는 사용 가능한 청크, 새 `plot`은 잠긴 칸까지 포함한 전체 예약 부지입니다.
처음 적용할 때 `lands-before-fixed-plot-*.yml`을 먼저 백업하고 전환합니다.
기존 청크가 모두 들어가는 2×2를 찾으면 빚·이웃·집터·사용 청크를 그대로 유지합니다.
이미 다른 집과 겹치거나 모양이 맞지 않으면 기존 집을 삭제·축소하지 않고 경고를 남기며 추가 해방을 막습니다.
기존 집은 부지 방향이 새 집과 다를 수 있습니다. 지도에는 저장된 예약 영역이 표시됩니다.

`/land admin addchunk <이름>`은 그 집 예약 영역의 잠긴 칸만 열고,
`removechunk`는 집터를 제외한 사용 칸을 다시 잠급니다. 예약 영역과 빚은 유지합니다.
집 포기·관리자 삭제는 잠긴 칸까지 포함한 전체 예약을 해제합니다.

## 설치 전 미리보기와 집터 위치

집터 아이템을 주 손에 들고 village에서 6블록 이내 바닥을 가리키면 설치 예정 2×2 청크 경계가 본인에게만 나타납니다. 청록색은 전체 부지, 초록색은 먼저 사용할 집터 청크입니다. 다른 집과 겹치거나 집 구역 밖이면 빨간색으로 표시합니다. 미리보기는 부지 검사용이며 WorldGuard 등 다른 플러그인의 설치 허용은 최종 설치 시 검사됩니다.

웅크리기+우클릭(공중/바닥)으로 집터 위치를 북서 → 북동 → 남동 → 남서로 바꿉니다. 위쪽은 북쪽을 뜻하며 플레이어 시선에 따라 바뀌지 않습니다. 웅크리기를 풀고 우클릭하면 선택한 배치로 설치됩니다. 선택은 접속 중 유지되며 재접속 시 북서로 초기화됩니다. 집터 청크부터 시작해 빚을 갚고 나머지를 한 청크씩 해방합니다. 기존에 설치한 집의 위치는 변경하지 않습니다.
