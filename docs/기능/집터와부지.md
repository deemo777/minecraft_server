# 집터와 2×2 부지

[명령어](../플러그인/ServerCore.md) · **3.27.0 기준**

## 이장과 대화

- 첫 우클릭: “광광서버에 오신걸 환영한다네”, 이후 “반갑다네”.
- **집터 수령**: 4청크·모서리 전환·청크 해방 안내 3장을 각각 **다 읽음** 체크 후 진행하고 마지막에 블록을 받습니다.
- 중간에 닫으면 다음 수령 시 읽던 장부터 진행합니다. 기존 집이나 가방의 집터가 있으면 중복 지급하지 않습니다.
- **빚 갚기**: 현재 빚 전액만 갚습니다. 빚이 없거나 잔액이 부족하면 비활성화되며, 부족 시 툴팁은 “돈이 부족합니다”입니다.
- 기존 서버의 `mayor.intro`, `pay-amounts`, `office` 설정은 새 대화에서 사용하지 않습니다. 월드·빚·집터 데이터는 유지합니다.

## 설치

1. village에서 집터를 들고 6블록 이내 바닥을 가리킵니다.
2. 청록색은 전체 부지, 초록색은 처음 사용할 집터 청크입니다. 빨간색은 부지 중복·구역 밖 등 설치 불가입니다.
3. **웅크리기+우클릭**으로 집터를 북서 → 북동 → 남동 → 남서 모서리로 바꿉니다.
4. 웅크리기를 풀고 우클릭해 설치합니다.

위쪽은 북쪽이며 시선 방향과 무관합니다. 선택은 재접속 시 북서로 초기화됩니다.
집이 없어야 하며 4청크 전체가 집 구역 안에 있어야 합니다. 다른 집과 빈 청크 간격은 필요 없고 부지 중복만 금지합니다.
WorldGuard 등 외부 보호의 허용 여부는 실제 설치할 때 검사됩니다.

## 빚과 해방

| 단계 | 사용 청크 | 기본 빚 |
|---|---|---|
| 설치 | 집터 1청크 | 50,000G |
| 다음 청크 해방 | 2청크 | 150,000G |
| 다음 청크 해방 | 3청크 | 500,000G |
| 마지막 청크 해방 | 4청크 | 1,000,000G |

이장에게 현재 빚을 다 갚고 집 지도에서 한 청크씩 해방합니다. 부지는 처음부터 4청크를 예약하며 집터 청크가 먼저 열립니다.
잠긴 칸은 주인·이웃도 사용할 수 없습니다. 기존에 설치한 집의 위치는 바뀌지 않습니다.

## 자주 쓰는 명령

| 명령어 | 용도 |
|---|---|
| `/land` · 집터 우클릭 | 집 지도 |
| `/land home` · `/land sethome` | 집 이동·귀환 위치 지정 |
| `/land trust <name>` · `/land untrust <name>` | 이웃 권한 |
| `/land show` · `/land info` | 경계·정보 |
| `/land kit` | 집이 없는 경우 집터 재수령 |
| `/land abandon confirm` | 집 포기·집터 반환·남은 빚 해제 |

집 포기·관리자 삭제는 부지 예약을 풀지만 건축물을 지우거나 복원하지 않습니다.
`lands.yml`은 예약 `plot`과 사용 `chunks`를 저장합니다. 구형 자료 전환 시 `lands-before-fixed-plot-*.yml`을 보존하며 부지가 맞지 않는 기존 집은 강제로 축소하지 않습니다.
