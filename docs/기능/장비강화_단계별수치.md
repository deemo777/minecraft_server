# 장비 강화 단계별 실제 수치

런타임 계산식으로 생성한 0~25강 전체 표입니다. 0강 철·5강 순수 다이아·10강 효율 III/행운 I/내구성 I·15강 효율 V/행운 III/내구성 III·20강 네더라이트 효율 VI/행운 3.5/내구성 IV·25강 효율 VII/행운 IV/무한 내구도를 기준으로 보간합니다. 속도는 완성된 기준점 사이를 선형 보간합니다. 효율의 소수 단계는 최종 작업 속도로 반영합니다.

0~24강은 바닐라와 같은 양의 내구도를 매번 소모합니다. 내구성 상당 효과는 총 내구도에 반영하여 I=2배, III=4배, IV=5배입니다. 재질의 기본 내구도도 0~5강 철→다이아, 15~20강 다이아→네더라이트로 보간합니다. 낚싯대/물뿌리개 바탕 내구도는 64/25입니다. 25강만 무한 내구도입니다. 기존 장비 갱신 시 손상 비율을 보존합니다.

원목 추가 수와 작업 칸 수는 고정 정수입니다. 곡괭이 연결 광석은 20강까지 직접 블록만, 21~25강 총 2/3/4/5/6개를 유지합니다. 채굴/벌목 속도는 적합한 블록에서의 기본 수치이며 경도·수중·공중 상태에 따라 실제 시간은 달라집니다.
