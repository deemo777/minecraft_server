# 커스텀 도구와 강화

마을 도구는 곡괭이·도끼·괭이·낚싯대·물뿌리개 5종이며 +0부터 +25까지 강화할 수 있습니다. 대장장이에게 도구와 전용 강화를 넣고 강화 버튼을 누릅니다. 일반 무기·방어구는 강화 대상이 아닙니다.

도구 5종 모두 외형은 **+0~9에 기존 +0 디자인**을 사용합니다. +0·+5 외형은 같고, 기존 +5·+10·+15·+20 디자인은 각각 새 +10·+15·+20·+25에서 열립니다. 성능 기준 단계는 바꾸지 않습니다.

| 실제 강화 단계 | 기존 모델 단계 | 곡괭이 | 도끼 | 괭이 | 물뿌리개 | 낚싯대 |
|---|---|---|---|---|---|---|
| +0~9 | +0 | talonpick | viridian_greataxe | iron_hay_sickle | 기본 bucket | wing lv00 |
| +10~14 | +5 | azure_pickaxe | black_iron_greataxe | windreaper | gilded_phoenix | wing lv05 |
| +15~19 | +10 | amethyst_greatpick | gloomsteel_greataxe | crystal_frostcythe | demons_blood | wing lv10 |
| +20~24 | +15 | viridian_pickaxe | berserkers_greataxe | revenants_darkscepter | viridian | wing lv15 |
| +25 | +20 | viridian_pickaxe | gilded_phoenix_greataxe | revenants_darkscepter | winterthorn | wing lv20 |

물뿌리개의 빈/full 모델과 낚싯대의 일반/cast 모델도 같은 단계로 이동합니다. 원본 모델 형상·UV·색·표시 자세는 유지하며 선택 기준만 바꿉니다. 원본 파일명의 단계 번호는 기존 디자인 번호를 유지합니다.

도구 설명에는 강화 별(★/☆)만 표시합니다. 성능·사용법·물 잔량·범위·작품 소개와 기본 인챈트·속성·내구도 무한 문구는 숨깁니다. `tools.yml`의 기존 `tools.*.lore`와 `lore-footer`는 사용하지 않으며 별 모양·색·줄당 개수는 `stars` 설정을 따릅니다. 실제 도구 성능과 물 저장은 유지하고 구매 창에는 가격·구매 안내를 표시합니다. 기존 보유 도구도 접속·손 교체·습득·인벤토리 닫기·재로드 때 갱신됩니다.

## 관리자 명령

```text
/npc create blacksmith
/npc remove blacksmith
/npc face blacksmith
/enhance [player]
/enhance material <type> <1~64> [player]
/villagetool give <type> [level] [player]
/villagetool level <0~25>
```

도구 ID는 `pickaxe`, `axe`, `hoe`, `fishing_rod`, `watering_can`입니다. `/villagetool level`은 손에 든 도구의 강화 단계를 바꿉니다.

## 강화 결정

마을 도구로 정상 작업을 하면 해당 도구의 강화 결정을 1개 얻을 수 있습니다. 기본 드롭률은 **2% + 플레이어의 관련 스킬 레벨 × 0.2%p**, 최대 **12%**입니다. 낚싯대는 이 최종 확률에 기본 **3배** 보정을 적용합니다. 도구 강화 단계나 바닐라 경험치 레벨을 사용하는 것이 아닙니다.

| 관련 스킬 레벨 | 1 | 10 | 20 | 30 | 40 | 50 |
|---|---|---|---|---|---|---|
| 일반 도구 결정 확률 | 2.2% | 4% | 6% | 8% | 10% | 12% |
| 낚싯대 결정 확률 (3배) | 6.6% | 12% | 18% | 24% | 30% | 36% |

| 도구 | 결정 획득 작업·관련 스킬 |
|---|---|
| 곡괭이 | 돌·광석 채굴 · 채광 |
| 도끼 | 나무 채집 · 벌목 |
| 괭이 | 다 자란 작물 수확 · 농사 |
| 낚싯대 | 실제 낚시 성공 · 낚시 |
| 물뿌리개 | 마른 경작지에 물주기 · 농사 |

설치한 돌·나무 재채굴, 크리에이티브·관전, 취소된 작업은 제외합니다. 일반 자수정은 강화 결정이 아닙니다. 스킬 기능이 꺼져 있으면 레벨 보너스 없이 기본 확률만 적용합니다.

## 강화 비용과 성공률

| 목표 단계 | 결정 소모 | 단계별 기본 성공률 |
|---|---:|---|
| +1~5 | 0 | 100 / 95 / 90 / 85 / 80% |
| +6~10 | 1 | 75 / 72.5 / 70 / 67.5 / 65% |
| +11~15 | 2 | 62.5 / 60 / 57.5 / 55 / 52.5% |
| +16~20 | 4 | 25 / 20 / 15 / 12 / 10% |
| +21~25 | 8 | 8 / 6 / 5 / 4 / 3% |

+1~5는 결정 슬롯이 비어 있어도 강화할 수 있으며, 슬롯에 넣은 결정도 소모하지 않습니다. +6 이상은 실패해도 해당 구간의 결정을 소모하고, 모든 유효한 강화 시도는 아래 골드 비용을 별도로 소비합니다. 결정 0개 구간도 골드는 필요합니다. 모든 단계에서 실패해도 현재 강화 단계를 유지하고 성공률 보너스와 장인의 기운이 누적됩니다. 도구 파괴는 없습니다. 창 닫기·로그아웃 시 투입한 아이템은 반환됩니다.

+6~15 기본 확률은 75%에서 단계마다 2.5%p 감소합니다. 소수 확률을 반올림하지 않고 판정·표시합니다. 기존 20개·25개 기본 확률 배열은 새 기본 배열로 자동 호환하며, 별도 사용자 지정 확률은 그대로 유지합니다.

기본 성공률은 `plugins/ServerCore/tools.yml`의 `enhancement.success-rates`, 결정 확률은 `enhancement.drop-chance`(기본), `enhancement.drop-per-skill-level`(레벨당 증가), `enhancement.drop-max-chance`(상한) 및 `enhancement.fishing-drop-multiplier`(낚시 최종 확률 배율, 기본 3)에서 설정하고 `/servercore reload`로 반영합니다. 낚시 보정 후 확률은 100%를 넘지 않으며 결정 개수는 성공 시 1개로 유지합니다. 기존 `drop-chance` 사용자 설정을 유지하고 새 레벨 보너스·상한은 누락 시 기본값을 사용합니다. 상한을 기본 확률보다 낮게 설정해도 기본 확률을 낮추지는 않습니다.

## 강화 골드 비용

비용은 **현재 단계가 아닌 목표 단계**를 기준으로, 누를 때마다 소비합니다. 성공·실패·장기백의 비용은 같으며 결정 소모는 기존 0/1/2/4/8개 규칙을 유지합니다.

| 목표 단계 | 시도당 골드 (단계 순서대로) |
|---|---|
| +1~5 | 500 / 500 / 500 / 500 / 500G |
| +6~10 | 1,000 / 1,500 / 2,000 / 2,500 / 3,000G |
| +11~15 | 3,000 / 3,750 / 4,500 / 5,250 / 6,000G |
| +16~20 | 6,000 / 7,500 / 9,000 / 10,500 / 12,000G |
| +21~25 | 12,000 / 16,500 / 21,000 / 25,500 / 30,000G |

강화 버튼 설명에 골드 비용과 보유 잔액을 표시합니다. `enhancement.gold-costs` 배열로 목표 +1~25의 비용을 정하고 `/servercore reload`로 반영합니다. 누락된 단계는 위 기본 비용을 사용합니다. 골드 기능이 꺼져 있거나 잔액·결정이 부족하면 시도하지 않고 골드·아이템·장인의 기운을 유지합니다. 강화 결과를 반영하는 중 오류가 발생하면 기존 아이템 복원을 시도하고 출금한 골드를 환불합니다. 실제 도구 설명은 계속 별만 표시합니다.

기본 성공률·장기백·골드 비용 기준으로 도구 하나를 0강부터 올릴 때의 누적 소모는 다음과 같습니다. 도구 구매비는 제외하고, 각 단계의 장인의 기운이 0%에서 시작하는 조건입니다.

| 목표 | 평균 누적 골드 | 최대 누적 골드 |
|---|---:|---:|
| +5 | 약 2,768G | 6,500G |
| +10 | 약 16,821G | 61,500G |
| +15 | 약 54,410G | 264,000G |
| +20 | 약 296,679G | 1,281,000G |
| +25 | 약 1,774,632G | 7,407,000G |

## 장인의 기운·장기백

[로스트아크 공식 재련 가이드](https://lostark.game.onstove.com/GameGuide/Pages/%EC%9E%AC%EB%A0%A8)의 실패 시 단계 유지·성공률 상승·기운 최대 시 확정 성공 구조를 서버 도구 강화에 맞춰 적용합니다. 아래 수치는 이 서버의 적용 규칙입니다.

- 실패할 때마다 **기본 성공률의 10%**를 다음 시도 확률에 추가합니다. 실패 10회부터 기본의 2배로 고정합니다. +1~9는 상한 100%, 목표 +10 이상은 장기백 천장 연장을 위해 일반 성공률 상한 99.99%입니다. 기본 확률 자체가 100%인 설정과 기운 100%의 확정 성공은 유지합니다. 예: 기본 3% → 3.3% → 3.6% … 최대 6%.
- 목표 +1~9는 실패하면 **해당 시도 성공률 ÷ 2.15**%p만큼 기운을 얻으며 최소 1%p입니다. 목표 +10~25는 기존 규칙의 최대 실패 횟수를 구한 뒤 그 2배에 기운이 100%가 되도록 실패당 누적량을 재산정합니다. 0.0001%p 단위로 올림해 저장합니다. 사용자 설정 확률도 같은 방식이며 0% 단계는 실패 200회 후 다음 시도에 확정 성공합니다.
- 기존 아이템에 저장된 실패 횟수와 기운은 보존하고 이후 실패부터 새 누적량을 적용합니다. 아래 천장 표는 각 단계의 기운이 0%에서 시작할 때 기준입니다. 이미 100%인 도구는 바로 다음 시도에 확정 성공합니다. 천장 횟수의 2배 연장이며 평균 강화 횟수가 2배가 되는 것은 아닙니다.
- 기운이 100%가 되면 **다음 시도**가 확정 성공합니다. 그 시도도 목표 단계의 결정과 골드 비용을 소비합니다. +1~5는 결정만 0개이며 골드는 시도당 500G입니다.
- 일반 성공·확정 성공 모두 해당 도구의 누적 실패 횟수와 기운을 초기화합니다. 기존 실패 시 단계 하락 규칙은 제거합니다.
- 도구별 다음 목표 단계와 누적 상태를 아이템 PDC에 저장합니다. 강화 창 닫기·접속 종료·서버 재시작·도구 양도 시 유지되며, 다른 도구와 공유하지 않습니다. 관리자가 실제 강화 단계를 바꾸면 누적 상태를 초기화하고, 같은 단계에서 이름·별·모델만 갱신하면 유지합니다. 도입 전 도구는 0%에서 시작합니다.
- 대장간 강화 버튼 설명에서 실제 성공률·누적 실패·기운·확정 여부를 확인합니다. 기운은 100% 미만에서 확정으로 오해하지 않도록 소수 둘째 자리까지만 버려 표시합니다. 실제 도구 설명에는 기존대로 별만 남깁니다. 실패·성공 안내는 해당 플레이어와 서버 로그에만 표시합니다.

| 목표 단계 | 기운 100%까지 실패 횟수 | 확정 성공 시도 번호 |
|---|---:|---:|
| +10~15 | 8회 | 9번째 |
| +16 | 14회 | 15번째 |
| +17 | 16회 | 17번째 |
| +18 | 20회 | 21번째 |
| +19 | 24회 | 25번째 |
| +20 | 28회 | 29번째 |

현재 기본 확률·비용에서 도구 하나의 예상 결정 소모량은 다음과 같습니다. 각 단계가 성공하면 누적 상태가 초기화되는 조건으로 계산했으며 사용자 지정 확률을 쓰면 달라집니다. 0→25 전체 평균은 약 110.97회·1,774,632G·결정 644.06개, 모든 단계가 천장에 도달하는 최대는 459회·7,407,000G·결정 2,695개입니다.

## 도구 성능

곡괭이·도끼·괭이(낫)·낚싯대는 1인칭에서 이전보다 아래쪽·화면 바깥쪽에 들도록 조정했습니다. 오른손은 오른쪽, 왼손은 왼쪽으로 이동하며 모든 강화 단계·낚싯대 cast 상태에 적용됩니다. 물뿌리개는 모든 강화 단계의 빈/full 상태에서 원래 1인칭 위치를 사용합니다. 원본 형상과 색상·크기는 유지하고 인벤토리·3인칭 표시는 유지합니다.

| 단계 | 곡괭이 | 도끼 | 괭이 수확 범위·행운 |
|---|---|---|---|
| +0~4 | 철, 인챈트 없음 | 철, 인챈트 없음 | 클릭한 작물 1칸 |
| +5~9 | 다이아, 인챈트 없음 | 다이아, 인챈트 없음 | 클릭한 줄의 좌우 포함 가로 3칸 |
| +10~14 | 효율 III, 행운 I·II 각 50% | 효율 IV | 가로 5칸 |
| +15~19 | 효율 V, 행운 III | 효율 V, 섬세한 손길 I | 클릭한 줄 5칸 + 앞줄 가운데 3칸, 총 8칸 |
| +20~24 | 효율 VI, 행운 IV, 연결 광석 1~5개 추가 | 효율 VI, 섬세한 손길 I, 연결 자연 원목 1~5개 추가 | 8칸, 행운 II |
| +25 | 효율 VII, 행운 IV, 연결 광맥 전체 | 효율 VII, 섬세한 손길 I, 연결 자연 나무 전체 | 플레이어 중심 5×5, 행운 III |

곡괭이·도끼·괭이는 +0~4에 실제 철 도구, +5부터 실제 다이아 도구를 사용합니다. 기존 아이템도 갱신 시 바탕 재질을 맞추며, 재질 전환 시 내구도 손상 비율을 보존합니다. 중간 단계는 직전 5단계의 성능을 유지합니다. 곡괭이 +10~14의 ‘행운 1.5’는 채굴 직전 행운 I·II를 각각 50%로 선택해 바닐라 드롭 계산에 적용합니다. 기존 도끼 단계당 2.5% 추가 드롭은 제거합니다. 채광·벌목 스킬의 2배 드롭은 커스텀 곡괭이·도끼에 중첩하지 않습니다.

연쇄 채굴은 +20에서 클릭한 블록 외 1개, +21~24에서 2~5개를 추가로 캡니다. +25는 연결된 자원 전체를 대상으로 하되 한 번에 최대 4,096개, 한 틱에 추가 블록 최대 32개로 제한합니다. 광석은 면으로 연결된 같은 광종(일반·심층암 혼합 포함), 나무는 대각선까지 연결된 같은 종류 자연 원목 중 자연 잎·균사 수관이 있는 나무를 대상으로 합니다. 플레이어 설치 자원·미로드 청크는 제외하고 수평 32칸·수직 64칸 이내에서만 탐색합니다. 추가 블록도 `Player.breakBlock`을 사용해 보호·내구도·경험치·드롭 판정을 거치며, 보호 거부·도구 교체·파손·접속 종료 시 중단합니다.

괭이 범위 수확은 같은 높이의 다 자란 밀·당근·감자·비트·네더 사마귀만 대상으로 합니다. +5~24의 좌우·앞 방향은 휘두르는 순간의 수평 시선을 가까운 동서남북으로 맞춥니다. +25는 클릭한 작물이 플레이어 중심 5×5 안에 있을 때 그 구역을 수확합니다. 범위 안의 어린 작물과 경작지는 추가로 건드리지 않고 자동 재파종은 하지 않습니다. 각 추가 작물은 보호 판정과 기존 비옥한 농지 수분 초기화를 거칩니다.

괭이의 주된 강화 가치는 범위 수확입니다. 바닐라 행운은 당근·감자의 수확량을 늘리지만 밀·비트는 주 생산물 대신 씨앗을 늘립니다. 모든 작물의 판매 수익을 같은 비율로 늘리는 기능은 추가하지 않습니다.

낚싯대는 기존 날개형 5종 디자인을 위 외형 표의 새 단계에 맞춰 사용합니다. 일반 모델과 던진 상태(`_cast`) 모델을 함께 옮기며 실제 낚시 성능은 유지합니다. 기존 도구 이름·성능·표시는 접속, 손 교체, 습득, 인벤토리 닫기, 설정 재로드 때 갱신됩니다. 모델을 보려면 최신 통합 리소스팩이 필요합니다.

모든 **+25 마을 도구**(곡괭이·도끼·괭이·낚싯대·물뿌리개)는 **내구도 무한**이며 떨어뜨려도 **용암·불 피해로 소멸하지 않습니다**. 기존 내구도 손상도 도구 갱신 시 복구됩니다. 기존 보유 도구는 접속·손 교체·습득·인벤토리 닫기·설정 재로드 때 갱신되며, +25 미만으로 낮추면 이 특성은 해제됩니다.

+0~24 물뿌리개는 처음에는 비어 있습니다. 주 손에 들고 물을 바라보며 우클릭하면 물 블록을 없애지 않고 최대 용량까지 보충합니다. 일부만 사용했을 때도 보충할 수 있습니다. **+25 물뿌리개는 보충 없이 물을 무한으로 사용합니다.** 새로 지급되거나 이전 물이 비어 있어도 바로 사용할 수 있습니다.

| 강화 | 물주기 범위 | 한 번 보충한 뒤 물주기 횟수 |
|---|---|---|
| +0~4 | 1칸 | 20회 |
| +5~9 | 좌우 총 3칸 | 25회 |
| +10~14 | 3×3, 총 9칸 | 30회 |
| +15~19 | 4×4, 총 16칸 | 35회 |
| +20~24 | 4×4, 총 16칸 | 40회 |
| +25 | 4×4, 총 16칸 | 무한, 보충 불필요 |

밭이나 그 위 작물을 우클릭하면 클릭한 밭과 같은 높이의 단계별 범위에서 마른 칸의 수분을 최대로 올리고 물방울 효과를 표시합니다. 좌우는 사용할 때 플레이어의 수평 시선을 가까운 동서남북으로 맞춘 방향을 기준으로 합니다. +5는 클릭한 칸과 좌우 한 칸씩이며, +10은 클릭한 칸 중심의 3×3입니다. +15~25의 4×4는 클릭한 칸에서 앞·오른쪽으로 한 칸 더 넓어집니다.

여러 칸에 물을 주어도 +0~24는 물을 **1회분만** 소모하며, 실제로 젖게 한 칸이 없으면 소모하지 않습니다. +25는 물을 소모하지 않습니다. 이미 젖은 칸과 보호 플러그인이 거부한 칸은 건너뛰고 강화 결정 획득 판정은 한 번만 합니다.

남은 횟수는 아이템에 저장되어 강화·재접속 후에도 유지됩니다. 도구 설명에는 물 잔량과 범위를 표시하지 않습니다. +0~24는 물이 1회분 이상이면 물이 든 모델을, 0회이면 빈 모델을 표시합니다. +25는 항상 물이 든 모델을 사용합니다. +24까지 강화하면 용량만 늘고 남은 물은 자동 보충되지 않으며, +25가 되면 무한 기능이 활성화됩니다. 단계가 낮아지면 무한 기능이 해제되고 저장된 횟수를 새 용량까지만 유지합니다. 이전 가득 찬 물뿌리개는 해당 단계의 최대 횟수로 이전하며 +25 미만의 이전 빈 물뿌리개는 비워 둡니다. 수리 가능한 도구는 대장장이 UI에서 수리합니다.

기존 `tools.yml`의 `max-level: 20`은 +25로 호환하며, 기존 기본 20개·25개 성공률 배열은 새 기본 확률로 자동 호환하고 사용자 지정 배열의 누락 단계는 새 기본 확률을 사용합니다. 새 외형 단계에 맞추려면 통합 리소스팩을 교체하고 새 SHA-1을 반영해야 합니다.
