# 커스텀 도구와 강화

기본 설정 기준 · 최대 **+25** · 설정: `plugins/ServerCore/tools.yml` · 반영: `/servercore reload`

## 명령어·구매가

| 명령어 (관리자) | 용도 |
|---|---|
| `/npc create weaponmerchant` | 잊혀진 명장 생성 |
| `/npc create blacksmith` | 대장장이 생성 |
| `/npc create repairer` | 수리 기사 생성 |
| `/npc remove <weaponmerchant 또는 blacksmith>` | NPC 제거 |
| `/npc face <weaponmerchant 또는 blacksmith>` | NPC 방향 변경 |
| `/weaponshop [player]` | 구매 창 열기 |
| `/enhance [player]` | 강화 창 열기 |
| `/repair [player]` | 수리 공방 열기 |
| `/enhance material <type> <1~64> [player]` | 전용 강화 결정 지급 |
| `/villagetool give <type> [level] [player]` | 도구 지급 (+0~25) |
| `/villagetool level <0~25>` | 손에 든 도구 단계 변경·기운 초기화 |

| 도구 | `<type>` | +0 구매가 | 결정 획득 작업 | 관련 스킬 |
|---|---|---:|---|---|
| 곡괭이 | `pickaxe` | 1,000G | 자연 돌·광석 채굴 | 채광 |
| 도끼 | `axe` | 1,000G | 자연 원목 벌목 | 벌목 |
| 낚싯대 | `fishing_rod` | 1,000G | 실제 낚시 성공 | 낚시 |
| 괭이 | `hoe` | 500G | 다 자란 작물 수확 | 농사 |
| 물뿌리개 | `watering_can` | 500G | 마른 경작지 물주기 | 농사 |

구매 조건: **집터 설치** · 강화 대상: 마을 도구 5종 · 인챈트 테이블·모루·숫돌: 기본 차단

## 수리 공방

수리 기사 우클릭 → 가운데 칸에 마을 도구 **1개** → 아래 **수리** 버튼. `/npc remove repairer`·`/npc face repairer`로 제거·방향 변경.

| 항목 | 값 |
|---|---|
| 대상 | 손상된 마을 도구 5종, 일반 장비 제외 |
| 비용 | **강화 단계별 기본요금 + 복구 내구도 1당 1G** |
| +0~9 기본요금 | **0G** |
| +10~14 기본요금 | **500G** |
| +15~19 기본요금 | **1,000G** |
| +20~24 기본요금 | **4,000G** |
| +25 기본요금 | **10,000G** |
| +10 · 최대 1,300 · 손상 200 | **700G** (500 + 200) |
| +15 · 최대 250 · 손상 50 | **1,050G** (1,000 + 50) |
| +20 · 손상 200 | **4,200G** (4,000 + 200) |
| 결과 | 내구도 100% 복구 |
| 유지 | 강화 단계·장인의 기운·물 잔량·이름·추가 데이터 |
| 정상 장비·무한 내구도·골드 부족 | 버튼 비활성화 |
| 창 닫기·로그아웃·종료 | 장비 반환 (사망 시 keepInventory 규칙 적용) |
| 기능 설정 | `config.yml`: `features.repairer: true`, economy·tools 필요, 변경 후 재시작 |

NPC 디자인과 수리 배경은 최신 리소스팩 필요. NPC는 관리자 명령으로 원하는 위치에 배치합니다.

기본요금은 해당 구간 요금 하나만 적용합니다. 정상·무한 내구도 도구는 비용을 받지 않습니다. 현재 +25 도구는 무한 내구도라 수리 버튼이 비활성화됩니다.

## 강화 확률·비용

**목표 단계 기준, 시도당 비용.** 성공·실패·확정 성공 모두 같은 비용을 소비합니다.

강화 버튼: **현재 → 목표 단계 / 골드 소모 / 성공률 / 장기백 %**. 전용 재료 부족 시 클릭 비활성화·회색 이름·`전용 재료 부족` 표시, 골드 부족 시 `골드 부족` 표시. +1~5는 결정 없이 활성화됩니다(골드 필요). 강화·수리 버튼 위에는 별도 아이템 그림을 덧씌우지 않습니다.

## 결정 드롭률

**관련 스킬 레벨 기준**, 성공 시 결정 **1개**. 설치 자원 재채굴·크리에이티브·관전·취소 작업 제외.

| 도구 | 확률 | 최대 |
|---|---|---:|

| 낚싯대 | 10% + 레벨 × 0.6%p | 40% (Lv.50) |

| 자연 채굴 대상 | Lv.0 기본 | 증가량 / 채광 Lv. | Lv.50 상한 |
|---|---:|---:|---:|
| 돌·심층암 | 2% | 없음 | 2% |

심층암 광석도 동일. 스킬 기능이 꺼지면 Lv.0 확률 적용. 낚시·희귀 광물 곡선은 일반 드롭률 설정과 별도 고정입니다.

## 도구 성능

모든 커스텀 장비는 실제 인챈트 없이 속성 수치와 플러그인 계산으로 효과를 적용합니다. 기존 장비는 접속·습득·보관함 열기·인벤토리 닫기·리로드 시 기존 인챈트를 제거합니다. 강화 단계·손상 비율·물 잔량·장인의 기운은 보존합니다. 기존 `allow-enchant` 설정과 무관하게 커스텀 장비의 인챈트 테이블·모루·숫돌 사용은 차단합니다.

아래 채굴 속도는 적합한 블록에서의 기본 속도 수치입니다. 블록 경도·수중·공중·다른 버프 등에 따라 실제 파괴 시간은 달라집니다. 내구도 절약은 최대 내구도 배수가 아니라 소모 1점마다 독립 계산하는 소모 확률입니다.

### 곡괭이

| 단계 | 재질 | 채굴 속도 | 광물 드롭 | 연결 광석 추가 | 내구도 소모 확률 |
|---|---|---:|---|---|---:|
| +0~4 | 철 | 6 | 기본 | 없음 | 100% |
| +5~9 | 다이아 | 8 | 기본 | 없음 | 100% |
| +10~14 | 다이아 | 18 | 보정 강도 1/2 각 50% | 없음 | 50% |
| +15~19 | 다이아 | 34 | 보정 강도 3 | 없음 | 25% |
| +20~24 | 네더라이트 | 46 | 보정 강도 4 | 1/2/3/4/5개 | 20% |
| +25 | 네더라이트 | 59 | 보정 강도 4 | 최대 4,095개 | 0% |

광물 배수형 드롭의 평균 배율은 보정 강도 1/2 혼합에서 약 1.542배, 3에서 2.2배, 4에서 약 2.667배입니다. 레드스톤·발광석 등은 배수 대신 개수 가산 및 상한을 적용하고, 잎·자갈 등은 별도 확률표를 적용합니다. 관련 수치 규칙은 `numeric-drops.yml`에 있습니다.

### 도끼

| 단계 | 재질 | 벌목 속도 | 원형 회수 | 연결 원목 추가 | 내구도 소모 확률 |
|---|---|---:|---|---|---:|
| +0~4 | 철 | 6 | 없음 | 없음 | 100% |
| +5~9 | 다이아 | 8 | 없음 | 없음 | 100% |
| +10~14 | 다이아 | 25 | 없음 | 없음 | 50% |
| +15~19 | 다이아 | 34 | 적용 | 없음 | 25% |
| +20~24 | 네더라이트 | 46 | 적용 | 1/2/3/4/5개 | 20% |
| +25 | 네더라이트 | 59 | 적용 | 최대 4,095개 | 0% |

원형 회수는 등록된 잎·책장·수박 등에서 원래 블록을 드롭하도록 계산합니다. 벌집·벌통은 저장된 벌을 아이템에 보존하고 파괴 시 같은 벌이 중복 방출되지 않도록 처리하며, 파괴가 취소되면 원래 저장 상태를 복원합니다.

### 괭이

| 단계 | 재질 | 완숙 작물 수확 범위 | 추가 드롭 보정 강도 | 내구도 소모 확률 |
|---|---|---|---:|---:|
| +0~4 | 철 | 1칸 | 0 | 100% |
| +5~9 | 다이아 | 가로 3칸 | 0 | 100% |
| +10~14 | 다이아 | 가로 5칸 | 0 | 50% |
| +15~19 | 다이아 | 5+3칸, 총 8칸 | 0 | 25% |
| +20~24 | 네더라이트 | 8칸 | 2 | 20% |
| +25 | 네더라이트 | 플레이어 중심 5×5 | 3 | 0% |

밀·비트는 씨앗, 당근·감자는 작물 개수에 보정을 적용합니다. 보정 강도만큼 성공 확률 4/7의 추가 추첨을 합니다. 네더 사마귀는 0~보정 강도 개를 균등 가산합니다. 미성숙 작물은 추가 보정이 없습니다. 자동 재파종은 하지 않습니다.

### 물뿌리개

| 단계 | 물주기 범위 | 보충당 사용 횟수 | 내구도 소모 확률 |
|---|---|---:|---:|
| +0~4 | 1칸 | 20 | 100% |
| +5~9 | 좌우 3칸 | 25 | 100% |
| +10~14 | 3×3 | 30 | 50% |
| +15~19 | 4×4 | 35 | 25% |
| +20~24 | 4×4 | 40 | 20% |
| +25 | 4×4 | 무한 | 0% |

물 보충은 주 손에 들고 물 우클릭. 여러 칸도 1회분만 소비하며 실제로 적신 칸이 없으면 소비하지 않습니다. 물 소모는 내구도 절약 확률의 영향을 받지 않습니다.

공통: +25 내구도 무한·드롭 아이템 불/용암 면역, 강화 성공 시 내구도 완전 회복. 연결 작업은 총 최대 4,096개·32개/틱이며 설치 자원·미로드 청크를 제외하고 보호 거부/도구 교체/파손/로그아웃 시 중단합니다. 커스텀 곡괭이·도끼에는 스킬 2배 드롭을 중첩하지 않고 괭이의 농사 스킬 보너스는 유지합니다.

## 주요 설정

| `tools.yml` 키 | 기본값 |
|---|---|
| `max-level` | `25` |
| `allow-enchant` | 이전 호환용, 현재 커스텀 장비에는 사용하지 않음 |
| `enhancement.success-rates` | 위 목표 +1~25 성공률 |
| `enhancement.gold-costs` | 위 목표 +1~25 골드 |
| `enhancement.drop-chance` | `0.02` |
| `enhancement.drop-per-skill-level` | `0.002` |
| `enhancement.drop-max-chance` | `0.12` |
| `stars.per-row` | `10` |

일반 광물 보너스 상한: `drop-max-chance - drop-chance` (최소 0). 기존 `repair.full-cost`·`fishing-drop-multiplier`·`tools.*.lore`·`lore-footer`는 사용하지 않습니다.
