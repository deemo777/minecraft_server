# 커스텀 도구와 강화

기본 설정 기준 · 최대 **+25** · 설정: `plugins/ServerCore/tools.yml` · 반영: `/servercore reload`

## 강화 결정 디자인

최신 리소스팩은 도구·무기별로 색과 커팅 모양이 다른 32×32 픽셀 보석을 표시합니다.

| 장비   | 보석    | 색·커팅         |
| ---- | ----- | ------------ |
|  곡괭이 |   토파즈 |  황금색 브릴리언트 컷 |
|   도끼 |  에메랄드 | 초록색 직사각 스텝 컷 |
|   괭이 |  페리도트 |     연두색 타원 컷 |
|  낚싯대 |  사파이어 |     파란색 쿠션 컷 |
| 물뿌리개 | 아쿠아마린 |    청록색 물방울 컷 |
|   단검 |    루비 | 붉은 분홍색 마퀴즈 컷 |
|   태도 |   자수정 |     보라색 육각 컷 |
|   대검 |    가넷 |   짙은 적색 방패 컷 |

기존 `enhancement_<type>` 모델 ID와 재료 판별 데이터·이름·획득 확률·강화 비용은 유지합니다. 이미 보유한 결정도 팩을 다시 받으면 새 디자인으로 표시됩니다. 무기 3종도 기본 자수정 조각 대신 전용 보석을 사용합니다. 팩을 끄면 기존처럼 기본 자수정 조각으로 표시됩니다.

원본 생성: `tools/make_blacksmith_art.py` · PNG: `tools/art/enhancement_*.png`.

기본요금은 해당 구간 요금 하나만 적용합니다. 정상·무한 내구도 도구는 비용을 받지 않습니다. 현재 +25 도구는 무한 내구도라 수리 버튼이 비활성화됩니다.

## 결정 드롭률

**관련 스킬 레벨 기준**, 성공 시 결정 **1개**. 설치 자원 재채굴·크리에이티브·관전·취소 작업 제외.

| ---------- | ---------------- | -----------: |
| 도끼·괭이·물뿌리개 |  2% + 레벨 × 0.1%p |          12% |
|        낚싯대 | 10% + 레벨 × 0.3%p | 40% (Lv.100) |

| 자연 채굴 대상            | Lv.0 기본 | 증가량 / 채광 Lv. | Lv.100 상한 |

## 도구 성능

작업 속도는 0강 철, 5강 순수 다이아, 10강 다이아 효율 III/행운 I/내구성 I, 15강 다이아 효율 V/행운 III/내구성 III, 20강 네더라이트 효율 VI/행운 3.5/내구성 IV, 25강 네더라이트 효율 VII/행운 IV/무한 내구도를 기준으로 구간별 선형 보간합니다. 0~24강은 내구도 소모 확률 없이 매번 바닐라와 같은 양을 소모하며 내구성 효과는 총 내구도에 2/4/5배로 반영합니다. 재질 기본 내구도는 0~5강 250→1,561, 5~15강 1,561, 15~20강 1,561→2,031로 보간합니다. 낚싯대/물뿌리개는 64/25 바탕입니다. 25강만 무한입니다. 기존 장비의 손상 비율·이름·모델·PDC를 보존합니다. 곡괭이 연결 채광은 20강까지 직접 블록만, 21~25강 총 2/3/4/5/6개로 유지합니다. 도끼는 10/15/20/23/25강에 추가 원목 1/3/4/5/7개이며 중간값을 보간 후 반올림한 고정 정수를 사용합니다. 10강 전에는 추가 원목이 없습니다. 원형 회수는 15강부터 확정입니다.

**[0~25강 전체 도구·무기 수치표](장비강화_단계별수치.md)**는 실제 런타임 계산식으로 생성됩니다. `./gradlew.bat exportEquipmentStats`로 다시 생성합니다.

| 기준 강화 | 곡괭이·도끼 속도 | 광물 추가 드롭 확률 | 원형 회수 | 내구도 소모율 |
| --- | --- | --- | --- | --- |
| 0 | 6 | 없음 | 없음 | 100% |
| 5 | 8 | 없음 | 없음 | 100% |
| 10 | 18 | 2배 33.33% | 없음 | 100% |
| 15 | 34 | 2·3·4배 각각 20% | 확정 | 100% |
| 20 | 46 | 2·3·4배 각각 18.33%, 5배 8.33% | 확정 | 100% |
| 25 | 59 | 2·3·4·5배 각각 16.67% | 확정 | 0% |

곡괭이 0~10강은 6 / 6.4 / 6.8 / 7.2 / 7.6 / 8 / 10 / 12 / 14 / 16 / 18입니다. 속도는 적합한 블록에서의 기본 수치이며 경도/수중/공중/외부 효과에 따라 실제 시간은 달라집니다. 곡괭이 드롭 강도는 0~5강 0, 10강 1, 15강 3, 20강 3.5, 25강 4이며 기준점 사이는 선형 보간합니다. 실제 인챈트를 붙이지 않고 행운과 같은 블록별 수치 계산을 사용합니다. 드롭 강도는 블록별 배수·추가 개수·확률표에 적용하며 자연적인 개수/확률 상한은 유지합니다.

원형 회수는 등록된 잎·책장·수박 등에서 15강부터 블록 자체를 확정 회수합니다. 벌집/벌통은 회수 성공 시 저장 상태를 보존하며 중복 방출을 막고 파괴 취소 시 복원합니다.

괭이 수확 칸 수는 `반올림(1 + 9×강화/25)`로 0강 1칸→25강 10칸이며 실제로도 같은 고정 정수입니다. 5~14강은 원래 바닐라 드롭 전체가 2배일 확률 10~100%, 15~25강은 기본 2배에 3배일 확률 10~100%입니다. 따라서 14강 기대값 2배→15강 2.1배로 증가합니다. 미성숙 작물은 보정하지 않으며 자동 재파종하지 않습니다.

물뿌리개 물주기 칸 수는 괭이와 같은 `반올림(1 + 9×강화/25)` 고정 정수로 0강 1칸→25강 10칸입니다. 물통 용량은 0~24강에서 20+강화 횟수입니다. 25강에서는 물이 무한입니다. 실제로 적신 칸이 없으면 물을 소비하지 않고 여러 칸이어도 물은 1회분만 사용합니다.

낚싯대는 강화당 대기·물고기 접근 시간을 2%씩 단축하며 25강에서 50% 단축합니다. 일반 물고기 1개 추가 획득 확률은 0~24강 `50%×강화/24`, 25강 100%입니다. 기본 보물/잡동사니 확률을 변경하거나 복제하지 않으며 기존 낚시 스킬 보너스는 별도로 유지합니다. 던질 때의 강화 단계·낚싯대 인스턴스·손을 기록하며 다른 낚싯대로 바꿔 추가 보상을 얻지 못하게 합니다.

작업 도구의 총 내구도는 재질 기본 내구도×(1+내구성 강도)를 반올림합니다. 매번 바닐라 내구도를 소모하므로 10강 3,122, 15강 6,244, 20강 10,155입니다. 25강만 무한이며 0~24강에는 소모 확률 추첨이 없습니다.

무기는 기존 250→1,561 최대치 보간과 소모 확률을 유지합니다. 25강 무한 내구도 및 드롭 아이템 불/용암 면역도 유지합니다. 기존 도구 갱신은 손상 비율·물 잔량·장인의 기운을 보존하고 강화 성공 시에만 내구도를 완전 회복합니다. 커스텀 도구를 바닐라 아이템으로 교체하지 않으며 이름·모델·강화·PDC를 유지합니다.

실제 인챈트와 임시 인챈트 도구는 사용하지 않습니다. 기존 장비는 접속·습득·인벤토리/보관함 열기·닫기·리로드 시 인챈트를 제거하고 새 수치를 적용합니다. `allow-enchant` 설정과 무관하게 인챈트 테이블·모루·숫돌 사용은 차단합니다. 연결 원목 작업은 25강 총 최대 8개(직접 1+추가 7)·32개/틱, 연결 광석은 최대 총 6개이며, 설치 자원·미로드 청크 제외·보호 거부/도구 교체/파손/로그아웃 시 중단합니다.

## 아이템 표시·채광 해금 규칙 (4.12.0)

실물 아이템의 사용법·성능·드롭 확률 설명을 넣지 않습니다. 무기·도구는 이름과 강화 별, 무기의 고유 추가 옵션을 표시하며 4.13.0부터 무기에 공격력 숫자 한 줄만 추가합니다. 기본 공격 속도/속성 툴팁도 숨깁니다. 강화 결정·금화·쿠키·슬롯 머신·집터·비옥한 농지의 설명을 제거하며 기존 장비는 접속·습득·보관함 열기 등에서 수량/PDC/손상 비율을 보존해 갱신합니다. 상점 가격과 강화·수리 결제 정보는 해당 화면에만 표시합니다.

5강 곡괭이에는 행운 보정과 연결 광석 추가 채광이 없습니다. 행운은 5강 0, 10강 I, 15강 III, 20강 3.5, 25강 IV로 기준점 사이를 보간합니다. 연결 광석은 20강까지 추가 0개, 21~25강은 추가 1/2/3/4/5개입니다. 연결된 자연 광석이 부족하거나 보호 거부·내구도 소진 등이 있으면 실제 채광 수가 줄어듭니다. 충분한 광맥에서 지정 수를 초과하지 않습니다.

광부 7레벨의 기본 스킬 2배 확률은 100레벨 확장 후 기본 설정에서 0.175%지만 커스텀 곡괭이에는 중첩하지 않습니다. 구리·청금석·레드스톤·네더 금처럼 바닐라 자체가 여러 개 드롭하는 광물은 행운이 없어도 한 블록에서 여러 개 나올 수 있습니다.

### 곡괭이의 실제 드롭 확률 (4.15.1)

행운 단계를 먼저 확률 선택하지 않습니다. 정수 행운의 바닐라 드롭 분포를 기준으로 각 최종 개수/배율의 확률을 보간하고 그 결과를 한 번 추첨합니다. 행운 수치는 내부 계산에만 쓰며 단계별 표에는 실제 배율별 확률을 표시합니다. 다이아·석탄·철·구리·청금석 등에 적용하는 배율이며 기본 드롭이 1개인 다이아에서는 그대로 최종 개수입니다.

- 9강: 1개 73.33%, 2개 26.67%.
- 10강: 1개 66.67%, 2개 33.33%.
- 행운 1.5 상당: 1개 58.33%, 2개 29.17%, 3개 12.5%. 2개 이상 확률은 41.67%로 행운 I의 33.33%보다 높습니다.
- 행운 II: 1개 50%, 2개/3개 각각 25%. 행운 III: 1개 40%, 2개/3개/4개 각각 20%.

기존의 두 단계 추첨과 최종 분포·기대값은 같습니다. 변경점은 최종 결과 확률을 직접 계산·추첨하고 실제 확률을 문서로 표시한다는 것입니다. 레드스톤은 추가 개수 분포를, 자갈은 부싯돌 확률표를 직접 보간합니다. 작물 전용 배율은 별도입니다.
