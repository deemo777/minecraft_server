# 커스텀 도구와 강화

마을 도구는 곡괭이·도끼·괭이·낚싯대·물뿌리개 5종이며 +0부터 +20까지 강화할 수 있습니다. 대장장이에게 도구와 전용 강화를 넣고 강화 버튼을 누릅니다. 일반 무기·방어구는 강화 대상이 아닙니다.

곡괭이 외형은 +0~4 `talonpick`, +5~9 `azure_pickaxe`, +10~14 `amethyst_greatpick`, +15~20 `viridian_pickaxe`입니다. +20은 +15와 같은 디자인을 사용합니다.

낫(괭이) 외형은 +0~4 `iron_hay_sickle`, +5~9 `windreaper`, +10~14 `crystal_frostcythe`, +15~20 `revenants_darkscepter`입니다. +20은 +15와 같은 디자인을 사용합니다.

도끼 외형은 +0~4 `viridian_greataxe`, +5~9 `black_iron_greataxe`, +10~14 `gloomsteel_greataxe`, +15~19 `berserkers_greataxe`, +20 `gilded_phoenix_greataxe`입니다.

물뿌리개 외형은 +0~4 bucket 기반 3D 물뿌리개, +5~9 `gilded_phoenix`, +10~14 `demons_blood`, +15~19 `viridian`, +20 `winterthorn`입니다. 모든 단계에서 빈 상태와 `full` 상태를 별도로 표시합니다.

## 관리자 명령

```text
/npc create blacksmith
/npc remove blacksmith
/npc face blacksmith
/enhance [player]
/enhance material <type> <1~64> [player]
/villagetool give <type> [level] [player]
/villagetool level <0~20>
```

도구 ID는 `pickaxe`, `axe`, `hoe`, `fishing_rod`, `watering_can`입니다. `/villagetool level`은 손에 든 도구의 강화 단계를 바꿉니다.

## 강화 결정

마을 도구로 정상 작업을 하면 기본 10% 확률로 결정 1개를 얻습니다.

| 도구 | 결정 획득 작업 |
|---|---|
| 곡괭이 | 돌·광석 채굴 |
| 도끼 | 나무 채집 |
| 괭이 | 다 자란 작물 수확 |
| 낚싯대 | 실제 낚시 성공 |
| 물뿌리개 | 마른 경작지에 물주기 |

설치한 돌·나무 재채굴, 크리에이티브·관전, 취소된 작업은 제외합니다. 일반 자수정은 강화 결정이 아닙니다.

## 강화 비용과 성공률

| 목표 단계 | 결정 소모 | 단계별 성공률 |
|---|---:|---|
| +1~5 | 1 | 100 / 95 / 90 / 85 / 80% |
| +6~10 | 2 | 75 / 70 / 65 / 60 / 55% |
| +11~15 | 3 | 50 / 45 / 40 / 35 / 30% |
| +16~20 | 4 | 25 / 20 / 15 / 12 / 10% |

실패해도 결정은 소모되고 골드는 들지 않습니다. +1~10 실패는 단계 유지, +11~15 실패는 30% 확률로 하락(최저 +10), +16~20 실패는 50% 확률로 하락(최저 +15)합니다. 도구 파괴는 없습니다. 창 닫기·로그아웃 시 투입한 아이템은 반환됩니다.

성공률과 드롭률은 `plugins/ServerCore/tools.yml`의 `enhancement.success-rates`, `enhancement.drop-chance`에서 설정하고 `/servercore reload`로 반영합니다.

## 도구 성능

| 곡괭이 단계 | 효율 | 행운 |
|---|---|---|
| +0 | 없음 (다이아 기본 성능) | 없음 |
| +5 | II | I |
| +10 | V | III |
| +15 | VI | IV |
| +20 | VII | IV |

중간 효율은 0~10에서 `floor(단계×0.5)`, 10~20에서 `5+floor((단계-10)×0.2)`입니다. 행운은 0~10에서 `floor(단계×0.3)`, 10~15에서 `3+floor((단계-10)×0.2)`이며 +15 이후 IV로 고정됩니다. 바닐라 행운 드롭을 사용하고 별도 채광 스킬 2배 보너스는 중첩하지 않습니다.

도끼는 자연 원목의 추가 드롭 확률이 단계당 2.5%(+20에서 50%)입니다. +20은 자연 잎·균사 수관에 연결된 같은 종류 원목을 연쇄 벌목합니다. 보호 이벤트와 내구도를 적용하고, 플레이어가 설치한 원목은 추가 드롭·연쇄 벌목에서 제외합니다.

낚싯대는 `fishing_rod_wing_progress_lv00/05/10/15/20` 날개형 성장 단계별 3D 외형을 사용합니다. +0~4/+5~9/+10~14/+15~19/+20에 각각 대응하며, 매 단계의 일반 모델과 던진 상태(`_cast`) 모델을 구분합니다. 원본 텍스처 색상과 표시 자세를 유지합니다. 기존 도구 이름·성능·표시는 접속, 손 교체, 습득, 인벤토리 닫기, 설정 재로드 때 갱신됩니다. 모델을 보려면 최신 통합 리소스팩이 필요합니다.

물뿌리개는 처음에는 비어 있습니다. 주 손에 들고 물을 바라보며 우클릭하면 물 블록을 없애지 않고 최대 용량까지 보충합니다. 일부만 사용했을 때도 보충할 수 있습니다.

| 강화 | 한 번 보충한 뒤 물주기 횟수 |
|---|---|
| +0~4 | 20회 |
| +5~9 | 25회 |
| +10~14 | 30회 |
| +15~19 | 35회 |
| +20 | 40회 |

밭이나 그 위 작물을 우클릭하면 같은 높이의 **3×3 경작지** 중 마른 칸의 수분을 최대로 올리고 물방울 효과를 표시합니다. 주변 최대 9칸에 물을 주어도 물은 **1회분만** 소모하며, 실제로 젖게 한 칸이 없으면 소모하지 않습니다. 이미 젖은 칸과 보호 플러그인이 거부한 칸은 건너뛰고 강화 결정 획득 판정은 한 번만 합니다.

남은 횟수는 설명에 표시되며 아이템에 저장되어 강화·재접속 후에도 유지됩니다. 물이 1회분 이상이면 물이 든 모델을, 0회이면 빈 모델을 표시합니다. 강화하면 용량만 늘고 남은 물은 자동 보충되지 않으며, 단계가 낮아지면 새 용량까지만 유지합니다. 이전 가득 찬 물뿌리개는 해당 단계의 최대 횟수로 이전하고, 이전 빈 물뿌리개나 물 정보가 없는 도구는 빈 상태를 유지합니다. 수리 가능한 도구는 대장장이 UI에서 수리합니다.
