# 커스텀 도구와 강화

기본 설정 기준 · 최대 **+25** · 설정: `plugins/ServerCore/tools.yml` · 반영: `/servercore reload`

## 명령어·구매가

| 명령어 (관리자) | 용도 |
|---|---|
| `/npc create weaponmerchant` | 잊혀진 명장 생성 |
| `/npc create blacksmith` | 대장장이 생성 |
| `/npc create repairer` | 수리 기사 생성 |
| `/npc remove <weaponmerchant 또는 blacksmith>` | NPC 제거 |
| `/npc face <weaponmerchant 또는 blacksmith>` | NPC 방향 변경 |
| `/weaponshop [player]` | 구매 창 열기 |
| `/enhance [player]` | 강화 창 열기 |
| `/repair [player]` | 수리 공방 열기 |
| `/enhance material <type> <1~64> [player]` | 전용 강화 결정 지급 |
| `/villagetool give <type> [level] [player]` | 도구 지급 (+0~25) |
| `/villagetool level <0~25>` | 손에 든 도구 단계 변경·기운 초기화 |

| 도구 | `<type>` | +0 구매가 | 결정 획득 작업 | 관련 스킬 |
|---|---|---:|---|---|
| 곡괭이 | `pickaxe` | 1,000G | 자연 돌·광석 채굴 | 채광 |
| 도끼 | `axe` | 1,000G | 자연 원목 벌목 | 벌목 |
| 낚싯대 | `fishing_rod` | 1,000G | 실제 낚시 성공 | 낚시 |
| 괭이 | `hoe` | 500G | 다 자란 작물 수확 | 농사 |
| 물뿌리개 | `watering_can` | 500G | 마른 경작지 물주기 | 농사 |

구매 조건: **집터 설치** · 강화 대상: 마을 도구 5종 · 인챈트 테이블·모루·숫돌: 기본 차단

## 수리 공방

수리 기사 우클릭 → 가운데 칸에 마을 도구 **1개** → 아래 **수리** 버튼. `/npc remove repairer`·`/npc face repairer`로 제거·방향 변경.

| 항목 | 값 |
|---|---|
| 대상 | 손상된 마을 도구 5종, 일반 장비 제외 |
| 비용 | **강화 단계별 기본요금 + 복구 내구도 1당 1G** |
| +0~9 기본요금 | **0G** |
| +10~14 기본요금 | **500G** |
| +15~19 기본요금 | **1,000G** |
| +20~24 기본요금 | **4,000G** |
| +25 기본요금 | **10,000G** |
| +10 · 최대 1,300 · 손상 200 | **700G** (500 + 200) |
| +15 · 최대 250 · 손상 50 | **1,050G** (1,000 + 50) |
| +20 · 손상 200 | **4,200G** (4,000 + 200) |
| 결과 | 내구도 100% 복구 |
| 유지 | 강화 단계·장인의 기운·물 잔량·이름·추가 데이터 |
| 정상 장비·무한 내구도·골드 부족 | 버튼 비활성화 |
| 창 닫기·로그아웃·종료 | 장비 반환 (사망 시 keepInventory 규칙 적용) |
| 기능 설정 | `config.yml`: `features.repairer: true`, economy·tools 필요, 변경 후 재시작 |

NPC 디자인과 수리 배경은 최신 리소스팩 필요. NPC는 관리자 명령으로 원하는 위치에 배치합니다.

기본요금은 해당 구간 요금 하나만 적용합니다. 정상·무한 내구도 도구는 비용을 받지 않습니다. 현재 +25 도구는 무한 내구도라 수리 버튼이 비활성화됩니다.

## 강화 확률·비용

**목표 단계 기준, 시도당 비용.** 성공·실패·확정 성공 모두 같은 비용을 소비합니다.

## 결정 드롭률

**관련 스킬 레벨 기준**, 성공 시 결정 **1개**. 설치 자원 재채굴·크리에이티브·관전·취소 작업 제외.

| 도구 | 확률 | 최대 |
|---|---|---:|
| 도끼·괭이·물뿌리개 | 2% + 레벨 × 0.2%p | 12% |
| 낚싯대 | 10% + 레벨 × 0.6%p | 40% (Lv.50) |

| 자연 채굴 대상 | Lv.0 기본 | 증가량 / 채광 Lv. | Lv.50 상한 |
|---|---:|---:|---:|
| 돌·심층암 | 2% | 없음 | 2% |
| 구리 | 5% | +0.2%p | 15% |
| 석탄·청금석·네더 금·네더 석영·금 | 8% | +0.2%p | 18% |
| 철·레드스톤 | 10% | +0.2%p | 20% |
| 다이아몬드 | 15% | +0.2%p | 25% |
| 에메랄드·고대 잔해 | 50% | +1%p | 100% |
| 기타 블록 | 0% | 없음 | 0% |

심층암 광석도 동일. 스킬 기능이 꺼지면 Lv.0 확률 적용. 낚시·희귀 광물 곡선은 일반 드롭률 설정과 별도 고정입니다.

## 도구 성능

성능은 **매 강화 단계마다 증가**합니다. 5강 단위 숫자는 곡선의 기준점이며 사이 단계도 선형 보간합니다. 연결 자원 추가 한도는 20~25강에서 급격한 마지막 단계 점프를 없애기 위해 기하 보간합니다. 정수 드롭 강도·작업 칸 수·연결 블록 수는 소수 부분만큼 확률로 한 개 더 적용합니다. 예: 평균 1.4칸은 1칸 60%·2칸 40%입니다. 도구 바탕 재질/모델 변경은 유지하지만 작업 속도는 재질 점프를 보정한 최종 수치를 사용합니다.

**[0~25강 전체 도구·무기 수치표](장비강화_단계별수치.md)**는 실제 런타임 계산식으로 생성됩니다. `./gradlew.bat exportEquipmentStats`로 다시 생성합니다.

| 기준 강화 | 곡괭이 속도 | 도끼 속도 | 광물 드롭 보정 강도 | 원형 회수 확률 | 내구도 소모 확률 |
|---|---:|---:|---:|---:|---:|
| 0 | 6 | 6 | 0 | 0% | 100% |
| 5 | 12 | 12 | 0.5 | 20% | 75% |
| 10 | 18 | 25 | 1.5 | 40% | 50% |
| 15 | 34 | 34 | 3 | 60% | 25% |
| 20 | 46 | 46 | 4 | 80% | 20% |
| 25 | 59 | 59 | 5 | 100% | 0% |

곡괭이 0~10강은 6 / 7.2 / 8.4 / 9.6 / 10.8 / 12 / 13.2 / 14.4 / 15.6 / 16.8 / 18입니다. 속도는 적합한 블록에서의 기본 수치이며 경도/수중/공중/외부 효과에 따라 실제 시간은 달라집니다. 드롭 강도는 블록별 배수·추가 개수·확률표에 적용하며 자연적인 개수/확률 상한은 유지합니다.

원형 회수는 등록된 잎·책장·수박 등에서 블록 자체를 확률 드롭합니다. 벌집/벌통은 회수 성공 시 저장 상태를 보존하며 중복 방출을 막고 파괴 취소 시 복원합니다.

괭이 평균 수확 칸 수는 기준 강화 0/5/10/15/20/25에서 1/3/5/8/16/25칸이며 그 사이도 증가합니다. 작물 드롭 강도는 0/0.25/0.5/1/2/3입니다. 밀·비트는 씨앗, 당근·감자는 작물 개수에 보정하고 네더 사마귀는 균등 개수를 가산합니다. 미성숙 작물은 보정하지 않으며 자동 재파종하지 않습니다.

물뿌리개 평균 물주기 칸 수는 1/3/9/16/20/25칸이며 사이 단계도 증가합니다. 물통 용량은 0~24강에서 20+강화 횟수입니다. 25강에서는 물이 무한입니다. 실제로 적신 칸이 없으면 물을 소비하지 않고 여러 칸이어도 물은 1회분만 사용합니다.

낚싯대는 강화당 대기·물고기 접근 시간을 2%씩 단축하며 25강에서 50% 단축합니다. 일반 물고기 1개 추가 획득 확률은 강화당 1%p씩 증가하여 25강에서 25%입니다. 기본 보물/잡동사니 확률을 변경하거나 복제하지 않으며 기존 낚시 스킬 보너스는 별도로 유지합니다. 던질 때의 강화 단계·낚싯대 인스턴스·손을 기록하며 다른 낚싯대로 바꿔 추가 보상을 얻지 못하게 합니다.

최대 내구도도 매 강화마다 증가합니다. 0→25강의 유한 최대치는 곡괭이/도끼/괭이 250→2,031, 무기 250→1,561, 낚싯대 64→128, 물뿌리개 25→100을 선형 보간합니다. 25강은 수치와 별개로 무한 내구도 및 드롭 아이템 불/용암 면역을 유지합니다. 기존 도구 갱신은 손상 비율·물 잔량·장인의 기운을 보존하며 강화 성공 시에만 내구도를 완전 회복합니다.

실제 인챈트와 임시 인챈트 도구는 사용하지 않습니다. 기존 장비는 접속·습득·인벤토리/보관함 열기·닫기·리로드 시 인챈트를 제거하고 새 수치를 적용합니다. `allow-enchant` 설정과 무관하게 인챈트 테이블·모루·숫돌 사용은 차단합니다. 연결 작업은 총 최대 4,096개·32개/틱, 설치 자원·미로드 청크 제외·보호 거부/도구 교체/파손/로그아웃 시 중단합니다.
