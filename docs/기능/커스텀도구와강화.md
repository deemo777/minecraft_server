# 커스텀 도구와 강화

기본 설정 기준 · 최대 **+25** · 설정: `plugins/ServerCore/tools.yml` · 반영: `/servercore reload`

## 명령어·구매가

| 명령어 (관리자) | 용도 |
|---|---|
| `/npc create weaponmerchant` | 잊혀진 명장 생성 |
| `/npc create blacksmith` | 대장장이 생성 |
| `/npc remove <weaponmerchant 또는 blacksmith>` | NPC 제거 |
| `/npc face <weaponmerchant 또는 blacksmith>` | NPC 방향 변경 |
| `/weaponshop [player]` | 구매 창 열기 |
| `/enhance [player]` | 강화 창 열기 |
| `/enhance material <type> <1~64> [player]` | 전용 강화 결정 지급 |
| `/villagetool give <type> [level] [player]` | 도구 지급 (+0~25) |
| `/villagetool level <0~25>` | 손에 든 도구 단계 변경·기운 초기화 |

| 도구 | `<type>` | +0 구매가 | 결정 획득 작업 | 관련 스킬 |
|---|---|---:|---|---|
| 곡괭이 | `pickaxe` | 1,000G | 자연 돌·광석 채굴 | 채광 |
| 도끼 | `axe` | 1,000G | 자연 원목 벌목 | 벌목 |
| 낚싯대 | `fishing_rod` | 1,000G | 실제 낚시 성공 | 낚시 |
| 괭이 | `hoe` | 500G | 다 자란 작물 수확 | 농사 |
| 물뿌리개 | `watering_can` | 500G | 마른 경작지 물주기 | 농사 |

구매 조건: **집터 설치** · 강화 대상: 마을 도구 5종 · 인챈트 테이블·모루·숫돌: 기본 차단

## 결정 드롭률

**관련 스킬 레벨 기준**, 성공 시 결정 **1개**. 설치 자원 재채굴·크리에이티브·관전·취소 작업 제외.

| 도구 | 확률 | 최대 |
|---|---|---:|
| 도끼·괭이·물뿌리개 | 2% + 레벨 × 0.2%p | 12% |
| 낚싯대 | 10% + 레벨 × 0.6%p | 40% (Lv.50) |

| 자연 채굴 대상 | Lv.0 기본 | 증가량 / 채광 Lv. | Lv.50 상한 |
|---|---:|---:|---:|
| 돌·심층암 | 2% | 없음 | 2% |
| 구리 | 5% | +0.2%p | 15% |
| 석탄·청금석·네더 금·네더 석영·금 | 8% | +0.2%p | 18% |
| 철·레드스톤 | 10% | +0.2%p | 20% |
| 다이아몬드 | 15% | +0.2%p | 25% |
| 에메랄드·고대 잔해 | 50% | +1%p | 100% |
| 기타 블록 | 0% | 없음 | 0% |

심층암 광석도 동일. 스킬 기능이 꺼지면 Lv.0 확률 적용. 낚시·희귀 광물 곡선은 일반 드롭률 설정과 별도 고정입니다.

## 도구 성능

| 단계 | 곡괭이 | 도끼 | 괭이 수확·행운 |
|---|---|---|---|
| +0~4 | 철 | 철 | 1칸 |
| +5~9 | 다이아 | 다이아 | 가로 3칸 |
| +10~14 | 효율 III, 행운 I·II 각 50% | 효율 IV | 가로 5칸 |
| +15~19 | 효율 V, 행운 III | 효율 V, 섬세한 손길 I | 5+3칸 = 8칸 |
| +20~24 | 효율 VI, 행운 IV, 연결 광석 1~5개 추가 | 효율 VI, 섬세한 손길 I, 연결 원목 1~5개 추가 | 8칸, 행운 II |
| +25 | 효율 VII, 행운 IV, 연결 광맥 전체 | 효율 VII, 섬세한 손길 I, 연결 자연 나무 전체 | 플레이어 중심 5×5, 행운 III |

| 범위 작업 제한 | 값 |
|---|---|
| 연결 채굴 +20/+21/+22/+23/+24 | 클릭한 블록 외 1/2/3/4/5개 |
| 연결 채굴 +25 | 총 최대 4,096개, 추가 블록 최대 32개/틱 |
| 연결 탐색 거리 | 수평 32칸 / 수직 64칸 |
| 범위 수확 대상 | 같은 높이의 완숙 밀·당근·감자·비트·네더 사마귀 |
| 제외·중단 | 설치 자원·미로드 청크 제외, 보호 거부·도구 교체·파손·접속 종료 시 중단 |

커스텀 곡괭이·도끼에는 스킬 2배 드롭을 중첩하지 않습니다. 괭이는 자동 재파종하지 않습니다.

| 물뿌리개 단계 | 범위 | 보충당 사용 횟수 |
|---|---|---:|
| +0~4 | 1칸 | 20 |
| +5~9 | 좌우 3칸 | 25 |
| +10~14 | 3×3 | 30 |
| +15~19 | 4×4 | 35 |
| +20~24 | 4×4 | 40 |
| +25 | 4×4 | 무한 |

물 보충: 주 손에 들고 물 우클릭. 여러 칸 물주기도 1회분만 소비하며, 실제로 적신 칸이 없으면 소비하지 않습니다. +15 이상 범위는 앞·오른쪽으로 확장됩니다.

**모든 +25 도구: 내구도 무한·드롭 아이템 불/용암 면역.** 물뿌리개 +25는 물 보충 불필요. 도구 설명은 강화 별만 표시합니다.

## 외형 단계

| 실제 단계 | 사용 모델 단계 |
|---|---:|
| +0~9 | 기존 +0 |
| +10~14 | 기존 +5 |
| +15~19 | 기존 +10 |
| +20~24 | 기존 +15 |

물뿌리개 빈/full·낚싯대 일반/cast 모두 동일. **+0과 +5 외형은 같습니다.**

## 주요 설정

| `tools.yml` 키 | 기본값 |
|---|---|
| `max-level` | `25` |
| `allow-enchant` | `false` |
| `enhancement.success-rates` | 위 목표 +1~25 성공률 |
| `enhancement.gold-costs` | 위 목표 +1~25 골드 |
| `enhancement.drop-chance` | `0.02` |
| `enhancement.drop-per-skill-level` | `0.002` |
| `enhancement.drop-max-chance` | `0.12` |
| `stars.per-row` | `10` |

일반 광물 보너스 상한: `drop-max-chance - drop-chance` (최소 0). 기존 `fishing-drop-multiplier`·`tools.*.lore`·`lore-footer`는 사용하지 않습니다.
