# 무기와 스킨

종류별 기본 디자인 1개와 추가 스킨 13개, 총 42종을 등록합니다. 추가 스킨의 획득/변경 UI는 아직 제공하지 않습니다. 스킨은 성능에 영향을 주지 않습니다.

## 무기 성장

공격력·공속·주변 피해는 `(강화/25)^1.5`를 진행률로 사용하여 0~25강 사이를 매 단계 보간합니다. 초반에는 비슷한 성능, 후반에는 단일/범위 특화가 두드러집니다. 실제 인챈트는 사용하지 않습니다.

| 종류 | 기본 디자인 | 0→25강 공격력 | 0→25강 공속 | 0→25강 주변 피해 비율 | 최대 타격 수 |
|---|---|---|---|---|---:|
| 단검 | iron_dagger | 4→10.7 | 3→4.5 | 10% 고정 | 2 |
| 태도 | uchigatana | 6→13 | 2→2.4 | 20%→77% | 3 |
| 대검 | black_iron_greatsword | 9→24 | 1.3→1.0 | 35%→180% | 5 |

사거리는 기존처럼 단검 2→2.5, 태도 3→3.5, 대검 3.5→4블록을 매 강화 +0.02씩 증가합니다. 최대 타격 수는 직접 대상 포함이며 주 대상에 가까운 주변 대상을 선택합니다. 일반 검은 이 제한을 적용하지 않습니다. 보호 기능이 취소한 타격은 되살리거나 다른 대상으로 빈자리를 채우지 않습니다.

주변 피해는 `1+공격력×주변 피해 비율`입니다. 대검의 100% 초과분은 주변 타격 이벤트에서 추가 계산합니다. **[0~25강 전체 스탯 표](장비강화_단계별수치.md)**는 실제 런타임 계산식에서 생성합니다.

## 25강 고유 효과

| 무기 | 효과 | 발동·지속·대기 |
|---|---|---|
| 단검: 추격 | 이동 속도 +20% | 같은 대상에 유효 직접 공격 3회 명중 시 2초, 재발동 대기 5초 |
| 태도: 공방일체 | 받는 피해 10% 감소 | 유효 직접 명중 후 2초, 재명중 시 시간 갱신 |
| 대검: 압도 | 맞힌 대상 이동 속도 -30% | 같은 공격에 3마리 이상 실제 피해 시 1초, 재발동 대기 3초 |

단검/태도는 공격 게이지 85% 이상이고 취소되지 않은 실제 피해가 들어간 직접 타격만 발동에 집계합니다. 단검의 연속 명중 간격은 최대 2초입니다. 다른 대상/다른 무기 인스턴스/손 변경 시 연속 기록을 초기화하며 무기 교체로 5초 재사용 대기를 초기화하지 않습니다. 자신의 추격/공방일체 효과는 해당 25강 무기를 주 손에 들어야 유지합니다. 취소/피해 0 타격 및 같은 공격의 중복 대상은 압도 집계에서 제외합니다.

모두 자동 발동하며 실제 인챈트나 물약 효과를 붙이지 않습니다. 전용 임시 이동 속성만 추가/제거하여 기존 다른 버프·둔화는 보존합니다. 압도는 동시에 여러 번 걸려도 30%를 중첩하지 않고 종료 시각만 갱신합니다. 종료/언로드/로그아웃 시 전용 속성을 정리합니다. 공방일체는 기존 피해 구성 요소를 함께 90%로 줄여 방어력 재계산으로 감소율이 달라지는 것을 막습니다.

## 상인·강화·수리

- `/npc create armsmerchant` 또는 `/armsmerchantnpc create`: 전용 무기 상인 생성.
- `/armsmerchantnpc remove|face`: 상인 제거/방향 변경.
- `/armsshop [player]`: 관리자 구매 창. 집터 설치 후 종류별 0강을 각 1,000G에 구매합니다.
- 기존 대장장이에서 확률·장기백·전용 결정·골드 비용을 공유합니다. 실패 단계 유지, 성공 시 내구도 완전 회복, 기존 수리 공방을 유지합니다.
- 전용 무기로 몹 처치 시 전투 스킬에 따른 확률로 결정을 얻습니다. `/enhance material dagger|tachi|greatsword <수량> [player]`도 지원합니다.
- `/villagetool give dagger|tachi|greatsword [level] [player]`: 관리자 지급.
- 내구도 소모 확률은 0~24강 100%, 25강 0%입니다. 25강 무한 내구도·드롭 아이템 화염 내성은 공통 보상입니다.
- 최대 내구도는 매 단계 증가하고 기존 장비 갱신 시 손상 비율을 보존합니다. 피격 무적 시간 전역 제거와 공격 게이지는 유지합니다.
