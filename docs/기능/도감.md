# 도감

도감 351개 항목은 미완료일 때 원래 아이콘의 채도 80%·밝기 85%를 유지해 비활성 상태로 표시합니다. 완료 항목은 원래 밝은 아이콘과 체크를 표시합니다. 아이템 이름만 표시하며 설명은 붙이지 않습니다. 팩이 없는 경우 이름의 어두운 색/완료 체크와 반짝임으로 상태를 구분합니다.

항목을 클릭하면 가방 36칸에 있는 해당 재료를 필요한 남은 수량까지만 차감해 누적합니다. 예를 들어 10개 항목에 3개를 등록하면 남은 숫자가 7로 바뀌고, 나중에 7개를 더 등록하면 완료됩니다. 요구량이 1·2·3 등인 항목에도 같은 규칙이 적용됩니다. 초과 수량과 다른 아이템, 갑옷·왼손은 차감하지 않습니다. 완료된 아이콘의 스택 크기는 1이므로 10 등의 숫자가 체크를 가리지 않습니다. 이미 완료된 항목은 추가 차감/보상을 하지 않습니다.

진행은 `dogam-data/<UUID>.yml`의 `deposits`에 저장하고 완료 기록은 기존 `found`를 유지합니다. 기존 완료 기록과 이전 `묶음:항목` 형식을 읽습니다. 클릭마다 임시 파일을 저장해 교체한 뒤 완료 보상을 지급합니다. 저장 실패 시 그 클릭의 차감과 누적량을 되돌리며 보상을 지급하지 않습니다. `/dogam reset`은 부분 등록도 초기화합니다.

검증: Java 25 `gradlew.bat build`의 `verifyCollection`은 다양한 요구량/보유량, 남은 수량, 완료 숫자 숨김, 저장/재시작/기존 기록/실패/초기화를 검사합니다. `python tools/verify_collection_pack.py --jar <26.3 클라이언트 jar>`는 전체 팩 JSON·PNG·참조와 351개 모델 쌍, 어두운 텍스처/알파 보존을 검사하고 비교 이미지를 `tools/build/collection_preview.png`에 만듭니다. 비교 이미지는 팩 텍스처로 구성한 예시이며 실게임 캡처가 아닙니다.

## 오류 텍스처 수정 (4.12.2)

클라이언트 로그의 미완료 도감 모델 347개에서 `Missing textures`를 확인했습니다. `servercore:disabled/...` PNG는 ZIP 안에 존재했지만 기본 텍스처 아틀라스의 수집 경로에 포함되지 않았습니다. 전체 팩 빌드가 블록·아이템 아틀라스 양쪽에 `disabled` 디렉터리 소스를 추가합니다. 기본 소스는 팩 스택에서 유지되며 일반 아이템·블록·체크·특수 머리 모델과 텍스처는 변경하지 않습니다.

검증기는 파일 존재 외에 어두운 텍스처 각각의 블록/아이템 아틀라스 포함 여부도 확인합니다. 이전 배포 ZIP이 이 검사에서 실패하는 것을 확인한 뒤 수정 ZIP을 검증합니다. 게임에는 교체된 팩을 다시 다운로드해 적용해야 하며, 기존 클라이언트 로그의 경고가 사라졌는지는 새 팩 로드 이후 확인해야 합니다.

## 미완료 아이콘 가독성 (4.12.3)

미완료 아이콘을 알아보기 쉽도록 기존 밝기 30%·채도 15%를 밝기 85%·채도 80%로 높입니다. 원래 색상과 명암을 대부분 유지하고 완료 아이콘의 원래 밝기·체크와 구분합니다. 배경·투명도·모델 형상·수집 기록·남은 수량 표시는 유지합니다.
