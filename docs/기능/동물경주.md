# 마을 동물 경주

**관리자·NPC·경기장 설정 없이 플레이어 혼자 시작할 수 있습니다.** `/race start`에서 동물과 금액을 고르고 확정하면 됩니다. 다른 사람은 `/race watch`로 같은 돼지·토끼·닭 경주를 무료로 구경하며 중간에 들어와도 현재 진행도를 봅니다. `/race`도 같은 창을 엽니다. 첫 참가 후 서버 전체에 관전 안내를 보내고 선두·접수 시간·결과를 공유합니다.

## 참가와 보상

1. 아래 동물 버튼에서 응원할 동물을 선택합니다.
2. 100G·500G·1,000G 중 참가금을 고릅니다.
3. 손실 가능성과 지급액을 확인하고 **경주 시작 · 참가 확정**을 누릅니다. 확정할 때만 골드가 차감됩니다. 이미 접수 중인 경기는 **참가 확정**으로 합류합니다.

한 경기당 한 동물에 한 번만 참가하며 확정 후 변경·자진 취소는 불가능합니다. 출발 후에는 참가할 수 없습니다. 각 동물의 승률은 **1/3**이고, 적중하면 **원금 포함 3배**를 지급합니다. 예를 들어 500G 참가 후 적중하면 1,500G를 받아 순이익은 1,000G입니다. 빗나가면 500G를 잃습니다. 베팅 수·금액·참가자의 신원은 추첨에 영향을 주지 않습니다.

기본 흐름은 첫 참가 → 20초 접수 → 12초 경주 → 8초 결과 표시 → 대기입니다. **참가자가 1명이어도 자동 출발**합니다. 서버 전체에서 한 경기씩 진행하며 다른 플레이어는 같은 경기를 관전하거나 접수 중 합류할 수 있습니다. 다음 경기는 다시 첫 참가자가 시작합니다. `config.yml`의 `race.countdown-seconds`(10~60), `duration-seconds`(8~30), `result-seconds`(5~30)를 바꿀 수 있습니다. 진행 중에는 시작할 때 읽은 시간을 사용합니다.

## 여러 사람이 현장에서 구경하기

첫 참가자 주변에서 임시 경기장을 자동으로 찾습니다. 플레이어의 현재 높이와 위·아래 1칸, 가까운 동서남북 방향·좌우 공간을 최대 60곳까지 검사합니다. 현재 로드된 청크만 사용하며 블록을 설치하거나 땅을 고치지 않습니다. 주변 사람은 현장에서 동물을 구경하거나 동물을 우클릭해 관전 창을 열 수 있습니다.

현장 표시에는 앞쪽 20블록(양 끝 포함 21칸), 폭 7블록, 높이 3블록의 빈 공간과 단단한 바닥이 필요합니다. 월드 경계 안이어야 합니다. **공간이 없거나 동물 표시가 차단돼도 공용 관전 창에서 같은 경주를 진행**합니다. 관리자의 경기장 지정이나 별도 건축은 필요하지 않습니다.

경기 중에는 세 동물과 안내·결승선 홀로그램, 레인·결승선 파티클을 표시합니다. 실제 동물은 AI·중력·충돌·피해·먹이 주기·목줄·아이템 드롭·블록 상호작용을 막고 서버가 같은 경로로 이동시킵니다. 경주 중 필요한 청크만 티켓으로 유지하고 종료 후 동물·홀로그램·티켓을 회수합니다. 경기장에 장애물이 생기거나 동물이 제거되면 현장 표시를 정리하고 관전 창에서 계속합니다. 승자·진행도·정산은 바뀌지 않습니다. 별도 리소스팩은 필요하지 않습니다.

## 선택 사항: 관리자 시연·관리

`/race settrack`은 관리자 무료 시연용 위치를 저장합니다. 일반 플레이어 경주의 자동 위치 선택에는 쓰지 않습니다. `/race demo`는 저장 위치에서 5초 뒤 무료 시연을 시작하며 위치가 없거나 사용할 수 없으면 관전 창에서 보여줍니다. `/race removetrack`으로 시연 위치를 지워도 일반 경주는 계속 사용할 수 있습니다. 위치 변경·시연은 대기 중에만 가능합니다.

`/race cancel`은 관리자가 접수·경주 중 경기를 취소하고 참가금을 환불하는 명령입니다. 우승 결과를 이미 정한 뒤 저장하는 중이면 정산을 계속합니다. 일반 시작·참가·관전에는 관리자가 필요하지 않습니다.

## 중단과 저장

차감된 참가금과 보관 기록을 `money.yml`에 함께 저장하며, 경기 전체의 당첨금 지급·참가금 소멸·보관 기록 삭제도 한 번의 원자적 파일 교체로 처리합니다. 저장 실패 시 메모리 잔액과 보관 기록을 되돌립니다. 저장 완료 전에는 지급 완료를 알리지 않고 신규 참가를 받지 않으며 재시도합니다. 정산·환불을 반복해도 중복 입금되지 않습니다.

창을 닫거나 접속을 종료해도 UUID 계정으로 정상 정산합니다. 접수·경주 도중 정상 종료·리로드·관리자 취소가 발생하면 원금을 환불합니다. 비정상 종료 시 저장된 미정산 참가금은 다음 시작에 환불합니다. 결과 정산을 저장하기 전에 비정상 종료한 경우에도 원금 환불로 처리합니다. `features.race: false`로 끄고 재시작해도 경제 기능이 켜져 있으면 미정산 참가금을 환불합니다. 경제 기능까지 끄면 다음 경제 기능 활성화 때 처리합니다.

`features.race`와 `features.economy` 변경은 재시작이 필요합니다. 일반 사용 권한은 `servercore.race`(기본 허용), 관리 명령은 `servercore.admin`입니다.

## 검증 및 적용

Java 25에서 `gradlew.bat build`로 필수 검증과 `verifyRaceRules`, `verifyWagers`를 실행합니다. 경주 진행도·역전·일관성·확률 표본·자동 위치 탐색·공간 부족·경기장 좌표와 참가금 재시작·중복 정산·중단 환불·여러 계정의 저장 실패 롤백을 검사합니다.

소스 빌드는 실제 Paper 서버의 렌더링·다른 플러그인 이벤트 개입을 검증하지 않습니다. 적용 시 두 클라이언트에서 현장 동물과 관전 창의 승자 일치, 접수 종료·중복 클릭·오프라인 지급·취소·리로드·동물 정리·청크 티켓 해제를 확인해야 합니다. 운영 서버 적용과 월드 변경은 별도 작업입니다.
