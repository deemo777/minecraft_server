`<이름>`은 필수 입력, `[이름]`은 생략 가능한 입력입니다. 꺾쇠와 대괄호 자체는 입력하지 않습니다.
게임 명령어는 채팅에서 `/`를 붙이고, 콘솔에서는 보통 `/` 없이 입력합니다.
`git`, `java`, `python`은 게임 채팅이 아닌 터미널에서 실행합니다.

설계 문서에 적힌 예정 명령어는 실제로 등록된 명령어와 다릅니다. 사용 가능한 명령어는 플러그인별 문서를 먼저 봅니다.

대장장이·재료 획득·성공률은 [대장간과 강화](기능/대장간과강화.md)를 봅니다.
