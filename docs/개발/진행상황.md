# 진행 상황

[전체 문서](../README.md) · 기준: 2026-10-27, 개발 소스 3.15.0.

## 이번 반영

- 집터를 설치할 때 2×2 부지 예약, 집터 1청크만 사용 가능.
- 기존 빚 상환 방식과 금액 유지, 고정 순서로 나머지 청크 해방.
- 집 사이 빈 청크 간격 제한 없음. 예약 영역 중복만 금지.
- 잠긴 청크 보호, 재시작 시 예약·해방 상태 유지, 기존 데이터 사전 백업과 안전 전환.
- 플러그인별 명령어·운영·설정·설계·개발 문서 분리.

## 이미 있는 기능

메뉴·도감·이장님·집 지도·골드·상점·스킬·칭호·HUD·안내서·점프 패드·도약.
3.13.0: 마을 도구 지급·단계 변경·인챈트 제한. 도구 모델은 4종×5단계 제작.

## 아직 구현하지 않은 것

- 도구 구매 GUI, 수리·내구도 보호·도구별 특수 능력. 대장장이 NPC·확률 강화·재료 드롭은 3.15.0에서 구현.
- 물뿌리개 물 저장·리필·범위 물주기, 낚싯대 커스텀 cast 모델. 마른 밭 한 칸 물주기는 구현.
- 직종 수입과 강화 비용 균형, 곡괭이 배수 안 A/B 최종 결정.
- 게시판·랭킹·점프맵 보상·도감 전시관·모종 구매.

## 운영 적용 후 확인

1. 새 JAR 한 개만 설치하고 `/version ServerCore` 확인.
2. 기존 `lands.yml` 전환 로그와 백업 확인.
3. 새 집 설치·부지 중복 차단·붙어 있는 집 허용·잠긴 칸 보호 확인.
4. 이장님 상환 → 다음 청크 선택 → 확인 → 새 빚 생성 확인.
5. 이웃·상자·물·피스톤·재시작·집 포기 확인.

자동 검사 통과는 실제 Paper 클라이언트에서 모든 조작을 확인했다는 의미는 아닙니다.
