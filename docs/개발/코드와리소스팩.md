# 코드와 리소스팩

[전체 문서](../README.md) · 개발 프로젝트 `ServerCore_2` 기준.

## 코드 위치

| 경로 (`src/main/java/com/htk/core/`) | 담당 |
|---|---|
| `ServerCore.java`, `CoreCommand.java` | 기능 시작·설정 reload·이동 지점 |
| `common/` | GUI·글리프·아이템·공통 도우미 |
| `land/` | 부지·미리보기·빚·보호·저장 |
| `tools/` | 마을 도구·대장장이·강화·재료 |
| `npc/` | 이장·상점·대장장이 모델 NPC 전환·공통 방향 |
| `merchant/` | 무기 상인·구매 창·골드 결제·환불 |
| `cookie/` | 광쿠키·요리사·방향·수령음 |
| `ranking/` | 점수표·채집 집계·홀로그램·누적 저장 |
| `mayor/`, `shop/`, `economy/` | 이장·상점·골드 |
| `skill/`, `hud/`, `dogam/` | 스킬·칭호·HUD·도감 |
| `menu/`, `guide/`, `jumppad/`, `longjump/` | 메뉴·안내서·이동 기능 |

## 리소스 생성

| 파일 (`tools/`) | 담당 |
|---|---|
| `build_pack.py` | 전체 팩 조립·ZIP·SHA-1 |
| `make_art.py` | 메뉴·도감·HUD 등 기본 그림 |
| `make_fishing_models.py` | 낚싯대 5단계·던진 상태 모델·실제 모델 미리보기 |
| `make_tool_models.py` | 도구 모델 생성 |
| `make_blacksmith_art.py` | 강화 배경·결정 |
| `make_npc_skins.py` | 표준 64×64 스킨 UV·7종 NPC 의상·투명 외피·소품 |
| `make_cookie_art.py` | 광쿠키 모델·입자·먹기 회전과 위치 |
| `art/deemo777_skin.png` | 제작에 사용하는 실제 스킨 원본 |
| `models/` | 도구 JSON·텍스처, [제작 규칙](../../tools/models/README.md) |

GUI 그림의 글리프·슬롯·좌표는 Java와 생성기에서 함께 맞춰야 합니다.
모델 생성기는 수동 모델을 덮어쓸 수 있으므로 편집한 파일을 먼저 보관하세요.

## 검사·배포

`gradlew.bat build`가 강화·집터·순위 검사를 함께 실행합니다. 테스트 위치는 `src/test/java/`입니다.
Java 25가 필요하며, [빌드 명령·리소스팩 적용](../운영/배포와백업.md)을 참고하세요.
과거 상세 설명은 [기존 README](../archive/기존_README.md)에 보존되어 있습니다.
