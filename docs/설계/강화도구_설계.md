# 마을 도구 + 강화 시스템 설계

> 상태: **설계 중 + 기초 코드 들어감 (3.13.0)**. 아래 "남은 결정"이 정해지면 최종 확인 후 나머지 작업.
> - 들어간 것: 도구 아이템(이름·별·종류·단계 데이터), 3D 모양 자리(강화 단계 → custom_model_data), 인챈트 금지,
>   관리자 `/마을도구 give|level`, `tools.yml` (`tools/VillageToolFeature.java`, `ToolType.java`)
> - 아직: 강화(비용·확률·실패), 도구별 능력, 내구도 1 남기기·수리, 대장장이 NPC·GUI, 구매
> 숫자는 전부 나중에 `tools.yml` 에서 바꿀 수 있게 만들 예정.

## 1. 흐름
바닐라 도구로 야생 → 이장님께 집터 받아 집 설치 → 빚 갚으며 정착 → 대장장이에게 **마을 도구**를 사서 직종(채광·벌목·농사·낚시)을 키우고 강화.

## 2. 도구
| 도구 | 직종 | 가격 | 살 수 있는 조건 |
|---|---|---|---|
| 🎣 마을 낚싯대 | 낚시 | 1,000G | 누구나, 처음부터 |
| ⛏ 마을 곡괭이 | 채광 | 5,000G | **집이 있으면** |
| 🪓 마을 도끼 | 벌목 | 5,000G | **집이 있으면** |
| 🌾 마을 괭이 | 농사 | 5,000G | **집이 있으면** |

- 검(전투)은 없음
- **성능**: 다이아 도구 그대로 (내구도 1,561). 더 좋아지는 건 강화 능력으로
- **모양**: 리소스팩 3D 모델, 강화 단계에 따라 바뀜 → 아래 "2-1. 모양"
- **이름**: 도구마다 판타지 이름, **5강마다 이름도 바뀜** (모양과 같이). 이름 뒤에 `+7`, 색은 +0 회색 → +5 초록 → +10 파랑 → +15 보라 → +20 금색 (`tools.yml` → `names`)

  | 단계 | ⛏ 곡괭이 | 🪓 도끼 | 🌾 괭이 | 🎣 낚싯대 |
  |---|---|---|---|---|
  | +0 | 돌울림 | 나무꾼의 서약 | 흙내음 | 잔물결 |
  | +5 | 깊은 메아리 | 숲울음 | 풍요의 손길 | 은빛 바늘 |
  | +10 | 드워프의 맥박 | 고목의 분노 | 새벽이슬 | 심해의 속삭임 |
  | +15 | 용암심장 | 이그드라실의 송곳니 | 황금 이랑 | 레비아탄의 실 |
  | +20 | 별을 캐는 자, 아스트라 | 세계수를 베는 자, 칼라드 | 대지의 노래, 세레스 | 바다왕의 부름, 넵투라 |
- **설명**: "마을 곡괭이 · 대장장이의 작품" + 별 20칸(강화 단계)과 능력 수치
- **인챈트 금지**: 인챈트 테이블·모루·숫돌에 못 올림. 설정 `allow-enchant: false` (나중에 인챈트 시스템을 만들 때 true 로)
  - 강화 속도는 인챈트가 아니라 별도 능력치(채굴 효율 속성)로 → 나중에 인챈트를 풀어도 겹치지 않음
- **넘기기**: 막지 않음 (바닐라 아이템처럼 주고받기 가능)

### 2-1. 모양 (3D 모델, 5강마다 바뀜)
- 바탕은 진짜 다이아 도구, 겉모습만 `setItemModel("servercore:village_pickaxe")` 로 교체 (집터 아이템과 같은 방식)
- **3D 모델** (Blockbench Java Block/Item 형식, 큐브로 만든 입체). 손·가방·땅에서 모두 이 모양
- **5강마다 모습이 바뀜**: +0 / +5 / +10 / +15 / +20 → 모델 5개
  - 플러그인이 강화 단계를 `custom_model_data` floats[0] 에 넣고, 리소스팩 `range_dispatch` 가 0/5/10/15/20 으로 골라요
  - 아직 없는 단계는 그 아래 단계 모양, +0 도 없으면 바닐라 다이아 모양 → 모델이 없어도 코드 먼저 만들 수 있음
- **그림체**: **테라리아 느낌** (사용자가 고른 참고: 테라리아 무기·곡괭이 그림)
  - 굵은 진한 테두리, 왼쪽 위 밝은 면·오른쪽 아래 그림자, 선명한 색, 보석·장식
  - 단계가 오를수록 화려하게: 돌·나무 → 금속·보석 → 빛나는 날·불꽃·별 같은 판타지 소재 (테라리아 곡괭이 단계처럼)
  - 테라리아 그림을 그대로 베끼지 않고 느낌만 (저작권) → 새로 그림
- **크기·분위기**: 아기자기한 농장 도구(스타듀밸리) 말고 **크고 멋있는 판타지 무기 느낌** (사용자 요청)
  - 도구는 48x48 픽셀 = 모델 24칸으로 바닐라보다 **1.5배 큼**. 손으로 쥐는 손잡이 끝은 바닐라와 같은 자리, 머리 쪽이 커짐
  - 가방 칸·액자·땅에서는 칸에 맞게 줄여서 보여줌
  - 공통: 별 모양 금 받침 + 큰 보석, 빛나는 룬, 줄무늬 손잡이 감개 + 금 고리, 보석 박힌 뾰족한 금 손잡이 끝
  - **화려하게**: 소재가 끝으로 갈수록 빛나는 마법 소재로 변함(수정·불타는 날), 도구 주변에 **떠 있는 조각**(수정·불꽃·잎), 흰 반짝이
  - **빛나는 부품**(룬·보석·수정·불꽃·반짝이)은 모델에 `light_emission` → 어두운 동굴에서도 밝게 보임 (게임에서 확인 필요)
- **만드는 방법**: `tools/make_tool_models.py` 가 픽셀 그림을 코드로 그리고, 부품마다 두께를 달리해 3D 로 만듦
  - 손잡이 1.25칸, 머리 2칸, 받침 2.5칸, 보석 3.5칸 이상 두께 → 옆에서 보면 보석이 튀어나와 있음
  - `--preview` 로 미리보기: 가방 칸 / 비스듬한 입체 / **1인칭으로 손에 든 모습**(계산으로 흉내 낸 근사, 실제 게임과 조금 다를 수 있음)
- **만든 것 (+0)**:
  - ⛏ **돌울림** — 어두운 돌 초승달 머리가 양 끝·왕관 가시로 갈수록 **빛나는 청록 수정**으로 + 청록 룬 + 머리 위에 떠 있는 수정 조각 2개 + 큰 청록 보석 + 붉은 가죽 감개
  - 🪓 **나무꾼의 서약** — 뿔 달린 큰 도끼날이 강철 → 달궈진 쇠 → **불타는 날**로 + 날 위로 떠오르는 불꽃 3개 + 불씨 룬 + 달궈진 창끝·뒷가시 + 루비
  - 🌾 **흙내음** — 낫처럼 휜 달빛 강철 날 + **빛나는 에메랄드 수정 날 끝** + 덩굴·잎·분홍 꽃 + 떠 있는 잎 + 에메랄드
  - 💧 **이슬방울** — 주석 물뿌리개 + 놋쇠 꼭지 + 파란 물방울 무늬. 크기는 그대로(32px), 도구가 아니라 **똑바로 들어요**
  - 🎣 낚싯대는 던진 모양이 따로 있어서 아직 (바닐라 모양)
  - 상위 단계는 기본형(+0)을 바탕으로 머리 크기·색·장식(보석, 빛나는 날)을 키워서 강해지는 느낌
- **순서**: 곡괭이 +0 기본형 먼저 → +5~+20 → 도끼·괭이. 낚싯대는 던진 모양(cast)도 따로 있어서 나중에
- **파일 자리** (만들어 둠): `tools/models/<도구>_<단계>.json`, 텍스처 `tools/models/textures/*.png`
  - `build_pack.py` 의 `VILLAGE_TOOLS`·`TOOL_TIERS` 가 읽어서 팩에 넣음. 규칙은 `tools/models/README.md`
  - 텍스처는 `servercore:block/...` 으로 부름 (입체 모델은 `item/` 으로 부르면 26.x 에서 체크무늬)

### 2-2. 💧 물뿌리개 (추가, 아이템만 들어감)
- 나중에 농사를 바꾸려고 넣음: **물 옆에 밭을 두는 게 아니라, 물뿌리개로 한 칸씩 물을 줘야 젖은 밭**이 되는 방식
- 지금은 도구 아이템만 (`/마을도구 give 물뿌리개`). 바탕은 당근 낚싯대 (우클릭해도 아무 일 없고, 내구도 막대를 물 양으로 쓸 수 있음)
- 이름: +0 이슬방울 / +5 봄비 / +10 샘의 정령 / +15 폭포의 숨결 / +20 하늘비의 여신, 레이나
- 정할 것 (농사 시스템 설계 때): 가격, 물 담는 양·채우는 법(물에 우클릭), 강화하면 범위(1칸 → 3칸 → 3×3…)·물 양, 젖은 밭이 마르는 시간, 3D 모양

- **재료**: +6부터 철 주괴, +11부터 다이아, +16부터 네더라이트 조각 (개수 미정)
- ⚠ 비용·확률은 **직종별 수입 계산 후 다시 조정 예정** (남은 결정 2)

### 실패하면
| 단계 | 실패 시 | 이 아래로는 안 내려감 |
|---|---|---|
| +1 ~ +10 | 골드·재료만 사라짐 | — |
| +11 ~ +15 | **30%** 확률로 한 단계 하락 | +10 |
| +16 ~ +20 | **50%** 확률로 한 단계 하락 | +15 |

- **구간 저장**: 5·10·15 에 닿으면 저장 → 그 아래로 안 내려감 (지금 표에선 +5 저장은 쓰일 일 없음)
- 도구 **파괴 없음**

## 4. 도구별 능력
### ⛏ 곡괭이
| 능력 | 내용 |
|---|---|
| 같이 캐기 | 붙어 있는 같은 광석 **3단계마다 +1개** (+3:1, +6:2, +9:3, +12:4, +15:5, +18:6) |
| 속도 | +0 = 다이아 곡괭이 → 단계마다 조금씩 → **+10 에 심층암 캐는 속도 = 효율 V 다이아의 1.5배** → +11부터 그대로 |
| 드롭 배수 | 행운 대신 2배 → 3배 → 4배 구간 방식. +20 평균 **3.2배** (안 A / 안 B, 아래) |

- 심층암이 네더랙처럼 즉시 캐지면 안 됨 (+10 속도로도 즉시 캐지지 않음). 일반 돌은 +10 에서 즉시 캐짐 (효율 V + 성급함 II 느낌) — 수치는 조정 가능
- 드롭 배수는 광석(석탄·철·구리·금·다이아·에메랄드·청금석·레드스톤·석영)에만, 같이 캔 광석에도 똑같이
- 곡괭이는 드롭 배수가 있어서 "2배 확률(단계마다 +0.25%)"은 없음 (레벨링 효과의 2배 확률은 그대로)
- 강화 안 된(+0) 곡괭이: 다이아 곡괭이와 같음 (드롭 배수 없음)

- 안 B: +6부터 고르게 증가. +10 은 행운 III 보다 조금 높음 (2.42)

### 🪓 도끼
| 능력 | 내용 |
|---|---|
| 같이 베기 | 붙어 있는 원목 **5단계마다 +1개** (+5:1, +10:2, +15:3, +20:4) |
| 속도 | 단계마다 조금씩. +20 에도 원목이 즉시 베이지 않는 수준 |
| 2배 확률 | 단계마다 +0.25% (+20 = 5%) |

### 🌾 괭이
| 능력 | 내용 |
|---|---|
| 범위 수확 (휘두르기) | 다 자란 작물을 캐면 주변의 다 자란 같은 작물도 같이 수확 |
| 수확량 증가 | 단계마다 평균 +5% (+20 = 평균 2배) |
| 자동 다시 심기 | 수확하면 씨앗을 자동으로 다시 심음 |

범위:
| 단계 | 범위 |
|---|---|
| +0 ~ +4 | 1칸 (범위 없음) |
| +5 | 바라보는 방향 기준 가로 3칸 |
| +10 | 3×3 |
| +15 | 3×5 (앞으로 길게) |
| +20 | 5×5 |

- 다시 심을 씨앗을 어디서 가져올지 설정으로 분리:
  - 지금 `replant-from: harvest` — 수확물에서 씨앗(당근·감자는 1개)을 빼서 심기
  - 나중에 **모종 구매 시스템**을 넣으면 `replant-from: inventory` — 가방의 모종 아이템을 1개 써서 심기 (없으면 빈 밭)

### 🎣 낚싯대
| 능력 | 내용 |
|---|---|
| 입질 빨라짐 | 단계마다 조금씩, **+10 = 미끼(Lure) III**, 이후 조금씩 |
| 희귀템 확률 | 보물(이름표·안장·마법책·앵무조개 껍데기 등)·열대어·복어가 잘 나옴. **+10 = 바다의 행운 III**, 이후 조금씩 |
| 한 마리 더 | 단계마다 +0.25% (+20 = 5%) |

### 공통 규칙 (같이 캐기·범위 수확)
- 같은 종류만 (철 광석과 심층암 철 광석은 같은 종류)
- 같이 캔 블록도 레벨링 경험치를 주고, 배수·2배 확률은 블록마다 따로 굴림
- 직접 놓은 블록, 남의 땅 블록은 같이 캐지 않음
- 같이 캔 개수만큼 내구도 소모
- **Shift 누르고 캐면 같이 캐기·범위 수확 꺼짐**
- 2배 확률은 레벨링 효과(Lv.50 = 2.5%)와 더해짐

## 5. 내구도·수리
- 닳지만 **1 남으면 부서지지 않고 "수리 필요"** → 능력(같이 캐기·배수·범위 등) 꺼짐
- 수리비 = 깎인 내구도 × **1G** × (1 + 단계 × 10%)
  - 다이아(1,561) 다 쓴 도구 완전 수리: +0 약 1,600G → +20 약 4,700G
  - ⚠ 다이아라 용암에 빠지면 타요 (네더라이트와 다름)

## 6. 대장장이 NPC (마을)
- `/blacksmithnpc create` · `remove` (이장님·상점 주인처럼 무적, 안 움직임)
- 클릭 → 상자 GUI, 탭 **[도구 사기] [강화] [수리]**
  - 강화: 도구를 올리면 비용·재료·성공 확률·실패 시 하락 확률·다음 단계 효과 표시 → [강화]
  - 수리: 도구를 올리면 수리비 표시 → [수리]
  - 도구 사기: 4종 + 가격, 집이 없으면 곡괭이·도끼·괭이는 잠김 표시

## 7. 설정 파일 `tools.yml` (예정)
- 도구 가격, 구매 조건
- 강화: 최대 단계, 비용 시작값·배율, 단계별 성공 확률, 하락 확률 구간, 저장 구간, 재료
- 능력: 같이 캐기 간격(곡괭이 3, 도끼 5), 속도 곡선, 곡괭이 배수 표, 2배 확률, 괭이 범위 표·수확량, 낚싯대 입질·희귀템 수치
- 수리비 배율, `allow-enchant`, `replant-from`

## 8. 남은 결정
1. **곡괭이 드롭 배수**: 안 A vs 안 B
2. **직종별 시간당 수입 계산 → 강화 비용·효과 기댓값 → 물가 재지정**
   - 스트리머 서버 공개 자료는 숫자가 거의 없음
     - 악어의 놀이터 시즌 1: 광부 시간당 약 1.5만 원, 가공품 마진 2~3배, 귀환서(500원) 같은 소모품
     - 띵타이쿤: 강화 계산기 사이트(띵보 등)가 있지만 아직 못 열어봄 — 앱 브라우저로 다시 시도하거나 스크린샷
   - 제안: 바닐라 수치(광석 빈도, 작물 성장 시간, 낚시 입질 시간)로 직종별 시간당 수입을 직접 계산
3. 강화 재료 개수
4. +0 모양 4개 확인 (테라리아 느낌으로 만듦 → 게임 안에서 보고 고칠 점) → 그다음 +5~+20
5. 물뿌리개 농사 시스템 (물 주기·젖은 밭·마르는 시간)
6. 위가 정해지면 최종 설계 확인 → "시작" 하면 코드 작업
