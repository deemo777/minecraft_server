# 설정과 저장 데이터

[전체 문서](../README.md) · 아래 파일은 서버의 `plugins/ServerCore/` 기준입니다.

## 설정

| 파일 | 내용 | 적용 |
|---|---|---|
| `config.yml` | 기능·집터·골드·이장·HUD·도약 | `/코어 reload`, 기능 켜기/끄기는 재시작 |
| `menu.yml` | 메뉴 버튼·이동 지점 연결 | `/코어 reload` |
| `dogam.yml` | 도감 항목 | `/코어 reload`, 새 모델은 팩 재빌드 |
| `shops.yml` | 상점 품목·가격 | `/코어 reload` |
| `skills.yml` | 경험치·칭호·레벨 효과 | `/코어 reload` |
| `tools.yml` | 도구·강화 성공률·재료 드롭률 | `/코어 reload` |
| `weapon-shop.yml` | 무기 상인의 0강 도구 가격 | `/코어 reload` |
| `ranking.yml` | 순위 배점·나무 공통 점수·집계 월드 | `/코어 reload` |
| `guide.yml` | 안내서 | `/코어 reload` |

## 저장 데이터

| 파일·폴더 | 내용 | 관리 |
|---|---|---|
| `points.yml` | 메뉴 이동 지점 | `/servercore setpoint` 등 |
| `lands.yml` | 집·예약 청크·해방·빚·이웃 | `/land` |
| `land-zones.yml` | 집 설치 허용 구역 | `/land zone` |
| `ranking-data.yml` · `.bak` | 네 분야 누적 점수·게시판 위치 | 서버 종료 후 백업 |
| `money.yml` | 골드 잔액 | `/money` |
| `skill-data/` | 사용자 스킬·칭호 | `/skill` |
| `dogam-data/` | 사용자 도감 | `/dogam` |
| 월드의 엔티티·청크 데이터 | NPC·요리사·설치 블록 기록 | 월드와 함께 백업 |

서버 루트의 `server.properties`는 리소스팩 URL·SHA-1 등이며 재시작으로 적용합니다.
집 크기는 코드상 2×2로 고정입니다. 기존 설정 파일은 새 JAR로 통째로 덮어쓰지 않습니다.
월드·저장 데이터·`.env`는 소스 Git에 넣지 않습니다.
