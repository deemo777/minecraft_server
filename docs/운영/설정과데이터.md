# 설정 파일과 저장 데이터

[전체 문서](../README.md)

경로는 서버 폴더 기준입니다. 설정 파일과 플레이 데이터는 구분합니다.

| 위치 | 내용 | 적용 |
|---|---|---|
| `server.properties` | 포트·기본 월드·리소스팩 URL/SHA-1 | 재시작 |
| `plugins/ServerCore/config.yml` | 기능·집터·NPC·도약·보호 설정 | 일반 설정은 `/코어 reload`, 기능 구성은 재시작 |
| `plugins/ServerCore/menu.yml` | 메뉴 버튼·이동 | `/코어 reload` |
| `plugins/ServerCore/dogam.yml` | 도감 항목 | `/코어 reload`, 새 종류는 팩 재빌드 |
| `plugins/ServerCore/shops.yml` | 상점 품목·가격 | `/코어 reload` |
| `plugins/ServerCore/skills.yml` | 경험치·칭호·효과 | `/코어 reload` |
| `plugins/ServerCore/tools.yml` | 도구 이름·단계·인챈트 허용 | `/코어 reload` |
| `plugins/ServerCore/guide.yml` | 안내서 | `/코어 reload` |
| `plugins/ServerCore/points.yml` | 메뉴 이동 지점 | 명령어로 관리 |
| `plugins/ServerCore/lands.yml` | 집 소유·예약 부지·사용 청크·빚·이웃 | 운영 데이터, 임의 삭제 금지 |
| `plugins/ServerCore/land-zones.yml` | 집을 지을 수 있는 청크 | `/land zone`으로 관리 |
| `plugins/ServerCore/money.yml` | 골드 잔액 | 운영 데이터 |
| `plugins/ServerCore/skill-data/` | 사용자 스킬 | 운영 데이터 |
| `plugins/ServerCore/dogam-data/` | 사용자 도감 | 운영 데이터 |
| `plugins/Multiverse-Core/` | 월드 등록·설정 | `/mv` 도움말 확인 |
| `plugins/FastAsyncWorldEdit/` | 편집 설정·스키매틱·기록 | FAWE 문서 확인 |
| `plugins/WorldGuard/` | 보호 영역·플래그 | WorldGuard 명령어로 관리 |
| `world/`, 기타 월드 폴더 | 청크·엔티티·플레이어 데이터 | 서버 종료 후 백업·이관 |
| `.env` | 비밀 환경 설정 | Git·문서에 값 공개 금지 |

집 고정 크기는 코드에서 2×2로 정합니다. 예전 `land.max-chunks`·`max-range` 값으로 모양을 바꾸지 않습니다.
새 JAR가 기존 설정을 통째로 덮어쓰지는 않습니다. 새 기본값과 운영 설정의 차이를 비교해 필요한 항목만 추가합니다.
