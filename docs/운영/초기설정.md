# 처음 서버 설정

[전체 문서](../README.md)

관리자 권한으로 진행합니다. 기존 월드를 삭제하거나 같은 이름으로 새로 만들지 않습니다.
월드가 등록되어 있는지 `/mv list`로 확인하고, 필요한 기존 월드는 `/mv import <이름> normal`로 등록합니다.

1. 로비 도착 자리: `/mv setspawn`, `/servercore setpoint lobby`.
2. 로비 이장님 자리: `/mayornpc create`.
3. 마을 도착 자리: `/mv setspawn`, `/servercore setpoint village`.
4. 야생 도착 자리: `/mv setspawn`, `/servercore setpoint wild`.
5. 상점 위치: `/shopnpc create fish`, `/shopnpc create crops`, `/shopnpc create ores`.
6. 마을 주택 구역: `/land zone pos1`, 반대 모서리에서 `/land zone pos2`, `/land zone add`.
7. `/land zone show`로 확인. 2×2 집 부지 전체가 구역 안에 들어갈 공간을 확보합니다.
8. `/mv modify lobby set difficulty peaceful`, `/mv modify village set difficulty peaceful`.
9. 공공시설은 FAWE로 영역 선택 후 WorldGuard로 보호합니다.

테스트: 새 사용자 이장님 대화 → 집터 → 마을 설치 → 2×2 예약 → 1청크만 건축 가능 → 빚 상환 → 다음 청크 해방.
이웃 허가, 집 이동, 집 포기, 공공시설 보호도 관리자 우회가 꺼진 상태에서 확인합니다.
