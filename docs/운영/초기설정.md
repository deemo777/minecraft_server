# NPC·게시판 초기 설정

[전체 명령어](../플러그인/ServerCore.md) · 관리자 권한으로 실행합니다.

## 이동 지점

각 도착 위치에 서서 실행합니다. 월드 스폰은 [Multiverse-Core](../플러그인/Multiverse-Core.md)에서 별도로 설정합니다.

```text
/servercore setpoint lobby
/servercore setpoint village
/servercore setpoint wild
```

메뉴에서 실제 사용하는 지점 이름은 `menu.yml`을 확인하세요. 로비는 peaceful, 마을은 normal+몹 생성 차단, 자원 월드는 normal로 운영합니다.

## NPC

각 NPC를 세울 자리에서 한 줄씩 실행합니다.

```text
/mayornpc create
/shopnpc create fish
/shopnpc create crops
/shopnpc create ores
/blacksmithnpc create
/cookienpc create
```

NPC는 블록 중앙에 생성됩니다. 요리사가 볼 방향의 반대를 보고 `/cookienpc face`를 실행하면 방향을 다시 맞출 수 있습니다.

## 집 구역

village에서 두 모서리 청크를 선택합니다.

```text
/land zone pos1
/land zone pos2
/land zone add
/land zone show
```

각 집의 2×2 청크가 모두 들어갈 공간을 확보합니다. 집 구역을 비워두면 마을 전체가 허용됩니다.

## 순위 게시판

각 게시판을 둘 위치에서 실행합니다. 글은 현재 위치보다 3블록 위에 생성됩니다.

```text
/rankboard create farm_top farming
/rankboard create mine_top mining
/rankboard create wood_top woodcutting
/rankboard create fish_top fishing
```

마지막으로 일반 플레이어 상태에서 NPC 클릭·집터 설치·권한·순위 집계를 확인하세요.
