# 배포와 백업

[전체 문서](../README.md) · **2026-10-28**

## 플러그인

1. 서버 정상 종료 → 월드와 `plugins/ServerCore/`를 저장소 밖에 백업.
2. `plugins/`의 기존 ServerCore JAR를 새 JAR 하나로 교체.
3. 재시작 → `/version ServerCore`로 적용 버전 확인.

현재 소스 버전은 **3.25.0**입니다. JAR 교체는 리소스팩 교체와 별개입니다.

## 통합 리소스팩

[릴리스](https://github.com/deemo777/minecraft_server/releases/tag/servercore) · [ZIP 다운로드](https://github.com/deemo777/minecraft_server/releases/download/servercore/servercore_pack.zip)

`server.properties`:

```properties
resource-pack=https://github.com/deemo777/minecraft_server/releases/download/servercore/servercore_pack.zip
resource-pack-sha1=68479acc6d7ae19e1742e7adf3be84c6ffe97790
```

위 SHA-1은 **2026-10-28 낚싯대 단계·던지기 모델 추가 팩** 기준입니다. 팩이 바뀌면 최신 업로드 값으로 갱신하세요.
URL은 유지하고 ZIP을 교체합니다. 업로드 후 실제 다운로드 파일의 해시를 검증합니다.
전체 서버에는 `servercore_pack.zip`을 사용하며 강화 전용 ZIP만으로 대체하지 않습니다.

## 개발 프로젝트에서 빌드

Java 25 환경의 `ServerCore_2`에서 실행합니다.

```powershell
.\gradlew.bat build
python tools/build_pack.py --jar "$env:APPDATA\.minecraft\versions\26.3\26.3.jar" --dogam src/main/resources/dogam.yml
```

- 플러그인: `build/libs/ServerCore-3.25.0.jar`
- 통합 팩: `tools/build/servercore_pack.zip`
- 팩 빌드 의존성: Pillow, PyYAML
- 운영 도감 항목이 소스와 다르면 `--dogam`에 운영 파일을 지정합니다.

## Git·백업

소스 저장소는 `deemo777/minecraft_server`의 `plugins` 브랜치입니다. OCI 실행 파일 저장소와 구분하세요.
일반 작업은 검사 → 커밋 → 푸시, 리소스 변경은 릴리스 ZIP도 교체합니다.

월드 추적 해제 커밋을 pull하면 기존 파일이 삭제될 수 있습니다. 추적 변경 전에는 월드와 `.env`를 외부에 백업하세요.
강제 푸시·`reset --hard`·`git clean`은 일반 배포 절차가 아닙니다. Git 동기화는 운영 월드 백업을 대신하지 않습니다.
